## Q1. MSE 是什么？

**问题原话**：「mse是什么」

**一句话答案**：MSE = **Mean Squared Error（均方误差）**，把每个样本"预测错多少"取平方、再对所有样本求平均，得到的一个数；越小说明在这批数据上拟合得越好。

### 1. 公式

$$J(m,c)=\frac1n\sum_{i=1}^{n}\big(y_i-(mx_i+c)\big)^2$$

### 2. 逐符号

| 符号 | 是什么 | 备注 |
|---|---|---|
| $n$ | 样本数 | 5 个数据点则 $n=5$ |
| $i$ | 第几个样本 | 从 1 到 $n$ |
| $x_i$ | 第 $i$ 个样本的 Feature（特征） | 如房屋面积 |
| $y_i$ | 第 $i$ 个样本的 Label（真实标签） | 如真实房价 |
| $mx_i+c$ | 模型预测值 $\hat y_i$ | $m,c$ 是 Parameter（参数），待学 |
| $y_i-\hat y_i$ | **Residual（残差）** | 正 = 猜低了，负 = 猜高了 |
| $(\cdot)^2$ | 平方 | 消去符号 + 重罚大错 |
| $\frac1n\sum_{i=1}^n$ | 求和再平均 | 让 Loss 与样本数无关 |

### 3. 三步心法

**Residual（残差） → Square（平方） → Mean（平均）**

名字就是公式直译：Mean = 平均，Squared = 平方，Error = 误差。

### 4. 为什么要平方

| 做法 | 好处 | 坏处 |
|---|---|---|
| 平方 $(\cdot)^2$ | 光滑可导，Gradient Descent 走得动；大错罚得重（错 2 倍 → 罚 4 倍） | 对 Outlier（离群点）敏感 |
| 绝对值 $\lvert\cdot\rvert$（即 MAE） | 抗 Outlier | 在 0 点不可导，没有斜率可跟 |

### 5. 为什么要平均

不除以 $n$，数据越多 Loss 越大，不同规模数据集无法比较。除以 $n$ 后单位是"目标值单位的平方"，所以常开根号得 **RMSE**，单位才回到原量纲。

$$\text{RMSE}=\sqrt{\text{MSE}},\qquad \text{MAE}=\frac1n\sum_{i=1}^n\lvert y_i-\hat y_i\rvert$$

### 6. 手算（笔记 P24 的数据）

三点 $(1,2),(2,4),(3,6)$，固定 $c=0$，只学 $m$：

$$J(m)=\frac13\big[(2-m)^2+(4-2m)^2+(6-3m)^2\big]$$

| $m$ | $J(m)$ | 含义 |
|---|---|---|
| 0 | $56/3\approx18.67$ | 全预测 0，最差 |
| 1 | $14/3\approx4.67$ | 半对 |
| 2 | $0$ | 完美拟合（数据正好在 $y=2x$ 上） |

**"训练"就是找让 $J$ 最小的 $m,c$**——这正是 P24 的问题"最好的 $m$ 和 $c$ 是什么"。

### 7. 易错点 / 考点

1. **MSE 不是 Accuracy（准确率）**。MSE 用于 **Regression（回归）**；分类用 **Cross-Entropy (CE，交叉熵)**（见 [`../L2/L2_qa.md`](../L2/L2_qa.md) Q1）。
2. **训练时叫 Loss（损失），评估时叫 Metric（指标）**。同一个公式，两种用途。
3. **MSE 小 ≠ 模型好**。训练集 MSE 低、测试集 MSE 高 = **Overfitting（过拟合）**。
4. **MSE 与 $R^2$ 不同**：$R^2$ 是无量纲的相对指标，MSE 有单位。

> 🔭 拓展（不影响本课）：MSE 等价于"噪声服从正态分布"假设下的最大似然。需要概率统计，暂不展开。

## Q2. Regularization（正则化）是什么意思？

**问题原话**：「正则化什么意思」

**一句话答案**：在 Loss 里额外加一项"惩罚模型太复杂"的分数，逼模型把参数压小，从而抑制 Overfitting（过拟合）。

**直觉**：考试不允许你把答案背得一字不差，逼你"理解着记"。因为背答案的模型（参数很大、曲线很弯）在新题上会崩。

### 1. 为什么需要它

L1 的现象：训练误差很低、验证误差很高 → 模型在背噪声。数学表现是**权重变得很大**：

$$w \text{ 大} \;\Rightarrow\; \text{输入稍微变一点，输出剧烈摆动} \;\Rightarrow\; \text{曲线很弯}$$

Regularization 的思路：**给"权重很大"本身扣分**，让模型在"拟合数据"和"别把权重搞太大"之间妥协。

### 2. 公式（以 L2 为例）

也叫 **Weight Decay（权重衰减）**：

$$J_{\text{total}}=\underbrace{\frac1n\sum_{i=1}^n (y_i-\hat y_i)^2}_{\text{原来的 MSE}}+\underbrace{\lambda\sum_j w_j^2}_{\text{惩罚项}}$$

| 符号 | 是什么 |
|---|---|
| $w_j$ | 第 $j$ 个 Weight（权重），**不含** $b$ |
| $w_j^2$ | 权重平方，越大罚越狠 |
| $\sum_j$ | 对所有维度权重都罚 |
| $\lambda$ | **Regularization Strength（正则强度）**，是 Hyperparameter（超参数），人设定，不由数据学 |

**惩罚有多狠**（$\lambda=0.1$）：

| $w$ | $w^2$ | 罚分 |
|---|---|---|
| 1 | 1 | 0.1 |
| 5 | 25 | 2.5 |
| 10 | 100 | 10 |

权重翻倍，罚分变四倍——模型会主动把没用的权重往 0 压。

### 3. $\lambda$ 调大调小会怎样

| $\lambda$ | 效果 |
|---|---|
| $=0$ | 无正则，回到普通 MSE，容易 Overfitting |
| 小 | 轻微约束，通常最好 |
| 很大 | 权重被压到接近 0，模型几乎只输出常数 → **Underfitting（欠拟合）** |

所以 $\lambda$ 必须用 **Validation Set（验证集）** 选——这也解释了"为什么测试集不能调参"。

### 4. L1 vs L2（常考）

| | **L2（Ridge，岭回归）** | **L1（Lasso，套索）** |
|---|---|---|
| 惩罚项 | $\lambda\sum_j w_j^2$ | $\lambda\sum_j\lvert w_j\rvert$ |
| 效果 | 权重整体压小，但不为 0 | 部分权重被压成恰好 0 |
| 附带作用 | 通用、稳定 | 顺带做 Feature Selection（特征选择） |

**为什么 L1 能压到 0**：平方项在 0 附近"罚得越来越轻"（斜率趋于 0），绝对值在 0 附近"罚得一样狠"，所以能一路压到 0。

### 5. 广义的 Regularization

凡是"限制模型自由度、防止背答案"的都算：

- **Early Stopping（早停）**：验证误差开始上升就停
- **Dropout**：训练时随机关掉一部分神经元
- **Data Augmentation（数据增强）**：翻转/裁剪图片，变相增加数据
- **Weight Sharing / 更小的网络**：直接减少参数

P31 的 TensorFlow Playground 里那个 "Regularization" 下拉框，调的就是 $\lambda$。

### 6. 易错点 / 考点

1. **Regularization 不是提高准确率的魔法**，是 **trade-off**：牺牲一点训练集表现，换验证/测试集表现。**训练误差变高是正常的**。
2. **惩罚项只在训练时加**。评估/预测只用原始 MSE 或 Accuracy，不把 $\lambda\sum w_j^2$ 算进去。
3. **bias $b$ 一般不罚**。罚 $b$ 只让模型整体偏移，没有"平滑"作用。
4. **$\lambda$ 是 Hyperparameter**，和 Learning Rate 一样要调，不是学出来的。
