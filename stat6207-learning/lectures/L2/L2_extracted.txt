Model Sharing-Based Deep Transfer Learning
The layers of a trained model can be fine-tuned 
Approach:
1. Find or train a model in source domain with large-scale training dataset
2. Part/all of the pre-trained network is reused in the architecture of the 
model for target model
3. Weights of the reused part can be updated through training on the target 
domain (a.k.a. fine-tuning)

=====PAGE 53=====
Instance-based Deep Transfer Learning
• Reweight the samples in the source domain to correct for marginal 
distribution differences
• Use only the relevant information from the source domain
• Work best when the conditional distribution is the same in both domains.
• Methods
1. finds and applies the weight that matches up the mean of the target and source 
domains. 
2. train a binary classifier to separate source samples from target samples that the 
output is the sample weights
53
[IMAGES] 2

=====PAGE 54=====
Instance-based Deep Transfer Learning
‘Some’ samples in the source domain can be utilized in the target domain with 
appropriate weights.
Approach:
1. Filtering out the samples that are not similar to the target.
2. Re-weighting instances in source domain to obtain a distribution similar to 
target domain.
3. Training a deep neural network on the collection of re-weighted instances 
as well as labeled instances (if any) in the target domain.

=====PAGE 79=====
Gemma 4 (E2B / E4B / 12B / 26B / 31B) — The Open Agentic Powerhouse
• Strengths:
• Native Multimodality: Offers built-in text, image, video, and native audio support (12B and smaller).
• Encoder-Free Architecture: The 12B variant feeds vision/audio directly into the LLM loop, saving 
memory and latency.
• Agentic Reasoning: Native <|think|> loop triggers massive gains in multi-step planning, coding, and 
math.
• Fast Local Speeds: Ships with Multi-Token Prediction (MTP) drafters out of the box for accelerated local 
inference.
• Weaknesses:
• Overly Strict Guardrails: Highly prone to false-positive refusals on harmless or ambiguous edge-case 
prompts.
• Modality Sensitivity: Requires strict, rigid prompt formatting (e.g., visuals before text) to prevent 
instruction drift.
• High MoE Memory Footprint: The 26B Mixture-of-Experts variant requires loading all 25B+ parameters 
into memory despite only routing ~3.8B per token

Qwen 3.6 (27B / 35B-A3B) — Next-Gen Agent & Thinking Powerhouse
• Strengths:
• Agentic Coding Leader: Heavily optimized for repository-level reasoning and front-end development 
workflows, excelling at complex coding challenges (e.g., scoring highly on SWE-bench Verified).  
• Thinking Preservation: Features a dedicated mechanism to retain and pass reasoning/chain-of-thought 
context seamlessly across multi-turn historical messages, making iterative debugging and development
