## Q1. Cross-Entropy（交叉熵）是什么？

**问题原话**：「交叉熵什么意思，请为我解释一下」

**一句话答案**：Cross-Entropy (CE，交叉熵) 是**分类任务**的损失函数：它只盯着"你给正确答案的概率"，给的越低罚得越重；二分类时就是 $L=-[y\log p+(1-y)\log(1-p)]$。

### 1. 先把它当"押题的代价"

把模型想成考生，$p$ 是它给**正确答案**下的注：

| 模型给正确类的概率 $p$ | 代价 $-\log p$ | 读法                             |
| ------------------------ | ---------------- | -------------------------------- |
| 0.99                     | 0.01             | 很确定且答对，几乎不罚           |
| 0.9                      | 0.105            | 答对，轻微代价                   |
| 0.5                      | 0.693            | 一半一半，中等代价               |
| 0.1                      | 2.303            | 答错，重罚                       |
| 0.01                     | 4.605            | **很自信地答错**，罚到爆炸 |

- 关键不是"错了扣一分"，而是**越自信地错，扣得越狠**。
- 预测越接近正确，$-\log p$ 越接近 0；$p\to0$ 时 $-\log p\to\infty$。

### 2. 二分类公式（Binary Cross-Entropy, BCE）

$$
L=-\big[\,y\log p+(1-y)\log(1-p)\,\big]
$$

| 符号                       | 是什么                                               |
| -------------------------- | ---------------------------------------------------- |
| $y\in\{0,1\}$            | 真实标签（0 或 1）                                   |
| $p=\sigma(w^Tx)\in(0,1)$ | 模型预测"属于类 1"的概率                             |
| $1-p$                    | 模型预测"属于类 0"的概率                             |
| $\log$                   | 自然对数 $\ln$；换底只差一个常数倍，不影响找最小值 |

**两项只有一项生效**：

- 若 $y=1$：$(1-y)=0$，只剩 $-\log p$ → 正确类概率越高越好。
- 若 $y=0$：第一项被 $y=0$ 消掉，只剩 $-\log(1-p)$ → 模型给类 0 的概率 $1-p$ 越高越好。

一个数据集上取平均：

$$
J=\frac1n\sum_{i=1}^n L_i
$$

### 3. 手算两个样本

| 样本 | 真实 $y$ | 预测 $p$ | 损失                     |
| ---- | ---------- | ---------- | ------------------------ |
| A    | 1          | 0.9        | $-\ln 0.9\approx0.105$ |
| B    | 0          | 0.9        | $-\ln 0.1\approx2.303$ |

$$
J=\frac{0.105+2.303}{2}\approx1.204
$$

- 样本 B 明明真实是 0，模型却给类 1 高达 0.9 的概率 → 重罚。
- 若两个样本都预测 0.5：每个 $-\ln0.5\approx0.693$，平均 0.693，反而比 1.204 小。
- 这说明 CE 奖励"**该确定时确定、不确定时老实说 0.5**"，不奖励盲目自信。

### 4. 为什么分类不用 MSE

MSE 是 $(y-p)^2$，把概率当普通数字；CE 把 $p$ 当概率，惩罚方式不同。

真正的差别在**梯度**（结论，不用链式法则推）：

| 组合          | 对打分 $z=w^Tx$ 的梯度 | 后果                                                    |
| ------------- | ------------------------ | ------------------------------------------------------- |
| Sigmoid + BCE | $p-y$                  | 错得越离谱，梯度越大，改得快                            |
| Sigmoid + MSE | $2(p-y)\,p(1-p)$       | 多出 $p(1-p)$，在 $p\approx0$ 或 $1$ 时把梯度掐断 |

**具体例子**：真实 $y=1$，模型自信地给了 $p=0.01$。

- CE 的梯度约 $-0.99$ → 强力把 $p$ 往上推。
- MSE 的梯度约 $-0.0196$ → 几乎不动，因为 Sigmoid 已经"饱和"。

> 一句话：**MSE 在模型最该被纠正的时候，反而没什么力气**；CE 不会。

### 5. 多分类：CE 只看正确类那一项

先算每个类的打分 $z_k=w_k^Tx+b_k$，再用 Softmax 变成概率：

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}},\qquad L=-\log p_{y}
$$

- $K$：类别数；$p_k$：第 $k$ 类的预测概率；$y$：真实类别编号。
- Softmax 保证 $p_k>0$ 且 $\sum_k p_k=1$。
- 损失只取**正确类**的概率 $p_y$：给 0.8 → $-\ln0.8\approx0.223$；给 0.1 → $\approx2.303$。
- 其余类不用单独罚：它们的概率被 $\sum p=1$ 约束，正确类低了，别类自然高。

> 🔭 拓展（不影响本课）：$K=2$ 时 Softmax 退化为 Sigmoid，多类 CE 也退化为 BCE。

### 6. 为什么叫"交叉"熵

> 记号提醒：这一段为了讲名字，把**真实分布记作大写 $P$**、**预测分布记作大写 $Q$**；前面 BCE 里的小写 $p$ 是"模型给类 1 的概率"，两者不是同一个符号。

- **Entropy（熵）**：$H(P)=-\sum_k P_k\log P_k$，描述"真实分布自己有多不确定"。
- **Cross-Entropy（交叉熵）**：$H(P,Q)=-\sum_k P_k\log Q_k$，用预测分布 $Q$ 去编码真实分布 $P$，代价多大。
- 标签是 One-Hot 时，$P$ 只有正确类为 1，于是

$$
H(P,Q)=-\log Q_y
$$

  这正好就是前面的 $L=-\log p_y$：**"交叉"= 拿预测分布 $Q$ 去对照真实分布 $P$**。

- 当 $Q=P$ 时 CE 最小，等于 $H(P)$；多出来的部分叫 KL Divergence（KL 散度）。

> 🔭 拓展：CE 也等于 Negative Log-Likelihood (NLL，负对数似然)；$e^{\text{CE}}$ 叫 Perplexity（困惑度），L3 讲语言模型时会遇到。

### 7. 易错点 / 考点

1. **CE 不是 Accuracy**：CE 衡量概率质量（还看"有多自信"），Accuracy 只数对几个。
2. **BCE 两项不是都算**：每条样本只有真实类对应的那一项生效。
3. **$p$ 必须是概率**：不能把打分 $z$ 直接塞进 $\log$；要先过 Sigmoid / Softmax。
4. **标签要 0/1 或类别编号**：多分类里 $y$ 是正确类的下标，不是 One-Hot 也行（取 $p_y$ 即可）。
5. **别给绝对概率**：$p=0$ 或 $1$ 会让 $\log$ 爆炸；代码里通常 clip 到 $[10^{-7},1-10^{-7}]$。
6. **PyTorch 的 `CrossEntropyLoss` 已内含 Softmax**：输入应是原始 logits，再手动 Softmax 就重复了（常见 bug）。
7. **CE 低 ≠ 一定泛化好**：它只说明训练集上的概率拟合好，仍要验证集/测试集。

### 8. 与课程的联系

- **L2 P10**：Sigmoid 把打分变成 $p$，训练时用 CE 而不是 MSE。
- **L3**：语言模型对"下一个 token"的预测就是一个多分类问题，CE 会成为主损失。
- 复习时把 CE 和 MSE 放在一起对比：**回归用 MSE，分类用 CE**（见 [`../L1/L1_qa.md`](../L1/L1_qa.md) Q1）。

## Q2. 为什么 ML 里到处都是 $e$ 和 $\log$？$\exp()$ 是不是就是 $e$ 的指数函数？

**问题原话**：「为什么机器学习里面会出现那么多的 e 和 log，想你详细生动的阐述他们的意义。exp（）是不是就是 e 的指数函数」

**一句话答案**：是的，$\exp(x)$ 就是 $e^x$，两者完全等价。而 ML 里 $e$ 和 $\log$ 成对出现，是因为它们是一对**翻译器**：$e^x$ 把"加法"翻译成"乘法"（用来造概率、造连续增长），$\log$ 再把"乘法"翻译回"加法"（用来把连乘的概率变成能相加的损失，并防止数值下溢）。

---

### 1. 先回答后半句：$\exp()$ 就是 $e$ 的指数函数

$$
\exp(x)=e^{x}
$$

- `exp` 是 exponential（指数）的缩写，只是**函数写法**，方便排版：$e^{x}$ 的上标在代码和公式里不好写，就写成 `exp(x)`。
- 所以 `np.exp(1)`、`torch.exp(x)`、计算器上的 $e^x$，都是同一件事。
- 四个必须记住的值：

| $x$  | $\exp(x)=e^x$ | 数值      |
| ------ | --------------- | --------- |
| 0      | $e^0$         | 1         |
| 1      | $e^1$         | 2.71828… |
| 2      | $e^2$         | 7.389     |
| $-1$ | $e^{-1}$      | 0.3679    |

- 最重要的性质（会算导数的你直接能用）：

$$
\frac{d}{dx}e^{x}=e^{x},\qquad \frac{d}{dx}\ln x=\frac{1}{x}
$$

- $e^x$ 是**唯一**（差常数倍意义下）导数等于自己的函数：**"变化速度 = 当前的量"**。
- 这正是所有"按比例增长/衰减"现象的形状，所以 $e$ 不是谁拍脑袋选的，它是这类现象的**天然单位**。

---

### 2. $e$ 到底是什么：连续增长的"天然单位"

先别看定义，看一个故事。你存 1 元钱，年利率 100%（先不管现实里有没有这种好事），看多久结一次利息：

| 一年结息次数 $n$ | 每次利率 | 年底拿到            | 算式                                |
| ------------------ | -------- | ------------------- | ----------------------------------- |
| 1（一年一次）      | 100%     | 2.000               | $(1+1)^1$                         |
| 2（半年）          | 50%      | 2.250               | $(1+\tfrac12)^2$                  |
| 12（每月）         | 8.33%    | 2.613               | $(1+\tfrac1{12})^{12}$            |
| 365（每天）        | 0.274%   | 2.7146              | $(1+\tfrac1{365})^{365}$          |
| 连续不断           | → 0     | **2.71828…** | $\lim_{n\to\infty}(1+\tfrac1n)^n$ |

$$
e=\lim_{n\to\infty}\left(1+\frac1n\right)^{n}\approx 2.718281828\ldots
$$

**符号解释 / 直觉**：

- $n$：一年复利多少次；$1/n$：每次的利率。
- 结息越密，钱越多，但**不会无限涨**，它撞到一个天花板，就是 $e$。
- 所以 $e$ 的身份证是：**"增长率恒等于自身大小"时，单位时间后的倍数**。
- 细菌每一刻都在分裂、放射性原子每一刻都在衰变、热水每一刻都在按温差散热 —— 这些过程的方程都是 $y'=ky$，解出来必然是 $y=y_0e^{kt}$。

**这就是为什么 ML 里到处都是 $e$ 的第一层原因**：只要模型里有"按比例放大/衰减"的机制（概率、温度、学习率衰减、指数加权平均），$e$ 就会自动冒出来。

---

### 3. $\log$ 是什么：$e^x$ 的反函数，一把"倍数的尺子"

$$
\ln x = \text{"}e\text{ 的几次方等于 }x\text{"}\quad\Longleftrightarrow\quad e^{\ln x}=x
$$

- $\ln$ 是 natural logarithm（自然对数），底就是 $e$。ML 论文/代码里的 $\log$ **默认都是 $\ln$**，不是 $\log_{10}$。
- 常用的几个值：$\ln 1=0$，$\ln e=1$，$\ln 0.5\approx-0.693$，$\ln 0.01\approx-4.605$。
- 它真正的本事只有一条 —— **把乘法降级成加法**：

$$
\ln(ab)=\ln a+\ln b,\qquad \ln\left(a^{b}\right)=b\ln a,\qquad \ln\frac{a}{b}=\ln a-\ln b
$$

**类比：分贝、地震震级、pH 值**。

- 声音能量相差 1000 倍，分贝只差 30；地震能量差 1000 倍，震级差 2。
- $\log$ 不关心"差多少"，只关心"差几倍"。它把 $10^{-300}$ 到 $10^{-3}$ 这种跨 297 个数量级的数，压到 $-690$ 到 $-6.9$ 这种能直接读的区间。
- 另一层直觉：$-\ln p$ 是"**惊讶度**"。$p=0.9$ 只惊讶 0.105；$p=0.001$ 惊讶 6.9 —— 越不可能的事发生，冲击越大。

---

### 4. 两者是一对：$e$ 管"加 → 乘"，$\log$ 管"乘 → 加"

| 方向         | 工具                     | 效果                                 | ML 里的用途                  |
| ------------ | ------------------------ | ------------------------------------ | ---------------------------- |
| 加法 → 乘法 | $e^{a+b}=e^a\cdot e^b$ | 把"打分相加"变成"概率相乘"           | Softmax、Sigmoid、高斯分布   |
| 乘法 → 加法 | $\ln(ab)=\ln a+\ln b$  | 把"概率连乘"变成"损失相加"           | Cross-Entropy、NLL、对数似然 |
| 往返         | $\ln(e^x)=x$           | 消掉指数，把乘积型目标变成平方型目标 | 高斯最大似然 → MSE          |

- 记住这张表，就记住了 80% 的"为什么这里有个 $e$ / 这里有个 $\log$"。
- 剩下 20% 是：导数需要（$e^x$ 求导最干净）和数值稳定（$\log$ 防止下溢）。

### 5. $e$ 在 ML 里出现的四个地方

**（1）Sigmoid：把任意打分压成概率**

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

- **为什么要有 $e$**：$z$ 可以是 $-100$ 也可以是 $100$，但概率必须落在 $(0,1)$。
- $e^{-z}$ 永远 $>0$，所以分母永远 $>1$，结果永远 $<1$；同时分母永远有限，结果永远 $>0$。
- 好处：**永远不会给出 $p=0$ 或 $p=1$**，也就不会让后面 $\log p$ 直接爆炸。
- 附带一个漂亮性质（结论，不用推）：$\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$，最大只有 0.25 —— 这就是"两端梯度消失"的根源。

**（2）Softmax：把一组打分变成一组概率**

$$
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

- **为什么是 $e$ 而不是别的**：三个理由，缺一不可。
  1. $e^{z_k}>0$ 恒成立 → 概率不会为负。
  2. $e^x$ 单调递增 → 谁打分高，谁概率大，**排序不变**。
  3. **差值变倍率**：$\dfrac{p_i}{p_j}=e^{z_i-z_j}$。打分只差 1，概率就差 $e\approx2.72$ 倍。
- 这条"差值 → 倍率"正是 Softmax 的灵魂：模型的打分是相对的，$e$ 把"领先 1 分"翻译成"多 2.72 倍把握"。
- **重要不变性**：$z$ 全部加同一个常数，概率不变（分子分母同乘 $e^{c}$）。所以 logits 有"平移自由度"，代码里减去最大值不影响结果（见第 8 节）。

**（3）高斯分布 / 正态分布：误差的"自然形状"**

$$
p(y\mid x)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(y-\hat y)^2}{2\sigma^2}\right)
$$

- 这里 $e$ 的指数是"**负的平方**"：误差越大，概率按 $e^{-\text{误差}^2}$ 急速下滑。
- 这就是"小误差很常见、大误差极罕见"的数学形状。
- **它直接解释了为什么回归用 MSE**（见第 6 节的手算）：把 $\exp$ 取 $\log$，平方就从指数里掉下来了。

**（4）所有"按比例衰减"的工程技巧**

- 学习率衰减：$\eta_t=\eta_0e^{-kt}$ 或 $\eta_t=\eta_0\gamma^{t}$。
- 指数移动平均（EMA，用于 BatchNorm 统计量、模型权重平滑）：$\bar\theta\leftarrow\beta\bar\theta+(1-\beta)\theta$，展开后就是 $\beta^t$ 的指数衰减。
- Dropout 的保留概率、温度采样、Label Smoothing 的权重，背后都是同一件事：**"距离越远，影响按倍数缩小"**。

### 6. $\log$ 在 ML 里出现的四个地方

**（1）Cross-Entropy：把"概率连乘"变成"损失相加"**

$$
L=-\log p_y,\qquad J=\frac1n\sum_{i=1}^{n}L_i
$$

- **没有 $\log$ 会怎样**：$n$ 个**独立**样本同时发生的概率是连乘 $p_1p_2\cdots p_n$。
- 每个 $p_i\approx0.01$、$n=1000$ 时，连乘 $=10^{-2000}$。float64 最小只能表示到约 $10^{-308}$，**直接变成 0**，梯度全没了。
- 取 $\log$ 后：$1000\times\ln0.01\approx-4605$，就是一个普通数字，能算、能比、能求导。
- 而且 $\log$ 单调递增，**不改变谁大谁小**，所以"最大化似然"和"最小化负对数似然"是同一件事。
- **为什么它能当损失**：$\dfrac{d}{dp}(-\ln p)=-\dfrac1p$。$p$ 越小，梯度越大 —— 错得越离谱，改得越狠，这正是我们要的惩罚形状。

**（2）最大似然 → MSE：$\log$ 把 $\exp$ 和平方"拆开"**

- 高斯假设下，$n$ 个样本的对数似然（log-likelihood）：

$$
\ln L=\sum_{i=1}^{n}\left[-\ln\!\left(\sqrt{2\pi}\sigma\right)-\frac{(y_i-\hat y_i)^2}{2\sigma^2}\right]
$$

- 第一项是常数，和参数无关；要最大化 $\ln L$，只需**最小化** $\sum_i(y_i-\hat y_i)^2$。
- 于是 MSE 出现了。**不是因为 MSE 天生正确，而是因为"假设误差服从高斯" + "取对数"这两步自然推出来的。**
- 换句话说：$\log$ 把"概率最大"翻译成了"平方和最小"，这才让回归问题可以只用加减乘除来训练。

**（3）Logit：把概率"拉直"成线性**

$$
\text{logit}(p)=\ln\frac{p}{1-p}=w^{T}x
$$

- $\dfrac{p}{1-p}$ 叫 odds（几率）：赢的概率是输的几倍。
- 取 $\log$ 后，$p\in(0,1)$ 被拉到整个实数轴 $(-\infty,+\infty)$，正好能等于一个线性打分 $w^Tx$。
- 这就是 L2 P10 那一页在做的事：**先假设"对数几率是线性的"，再反解出 Sigmoid**。Sigmoid 不是凭空规定的，是"线性 + $\log$"推出来的。

**（4）Perplexity 与信息量：把 nats 翻译成"几选一"**

$$
\text{Perplexity}=e^{\text{CE}}
$$

- CE 的单位是 nats（用 $\ln$ 时的信息单位）；$e^{\text{CE}}$ 把它翻译成"**等效于在多少个等概率选项里瞎猜**"。
- 例：$\text{CE}=2.303$ → $e^{2.303}\approx10$ → 相当于在 10 个词里猜一个。
- 换成 $\log_2$ 就是 bits，两者只差常数 $1/\ln2\approx1.443$ 倍，**不改变最优点**。L3 讲语言模型时会天天见到这个数。

---

### 7. 手算：三个能立刻验证的例子

**例 A：$\log$ 救了下溢**

- 1000 个 token，模型给每个正确 token 的概率都是 0.01。
- 连乘：$0.01^{1000}=10^{-2000}$ → 在 float64 里**就是 0.0**。
- 取对数：$1000\times\ln0.01=1000\times(-4.60517)=-4605.17$ → 正常数字。
- 平均：$-4.605$ nats/token；Perplexity $=e^{4.605}\approx100$ → "相当于在 100 个词里猜"。

**例 B：Softmax 的"差 1 分 = 2.72 倍"**

- 打分 $z=(2,1,0)$：

$$
e^{2}=7.389,\quad e^{1}=2.718,\quad e^{0}=1,\quad \text{和}=11.107
$$

$$
p=\left(\frac{7.389}{11.107},\frac{2.718}{11.107},\frac{1}{11.107}\right)=(0.665,\ 0.245,\ 0.090)
$$

- 检查倍率：$p_1/p_2=0.665/0.245=2.718=e$。差 1 个 logit，就是 $e$ 倍把握。
- 检查平移不变：$z=(102,101,100)$ 结果完全一样。

**例 C：高斯 → MSE**

- 一个样本，真实 $y=3$，预测 $\hat y=1$，设 $\sigma=1$。
- 高斯概率：$p=\dfrac{1}{\sqrt{2\pi}}e^{-(3-1)^2/2}=\dfrac{1}{2.5066}e^{-2}=0.399\times0.1353=0.0540$。
- 取对数：$\ln0.0540=-2.919$；直接套公式：$-\ln\sqrt{2\pi}-\dfrac{(2)^2}{2}=-0.919-2=-2.919$ ✓。
- 现在把预测改成 $\hat y=2$（误差 1）：$-\ln\sqrt{2\pi}-0.5=-1.419$，**更接近 0 = 似然更大**。
- 结论：让 $-\ln p$ 变小 ⟺ 让 $(y-\hat y)^2$ 变小 ⟺ MSE。完全等价。

---

### 8. 为什么偏偏是 $e$，不是 2 或 10？

- **导数最干净**：$\dfrac{d}{dx}a^{x}=a^{x}\ln a$。只有 $a=e$ 时 $\ln a=1$，多出来的常数因子消失。用 2 当底，每求一次导就多一个 $\ln2$。
- **反函数最干净**：$\dfrac{d}{dx}\log_a x=\dfrac{1}{x\ln a}$，同样只有 $e$ 让分母只剩 $x$。
- **换底只是乘常数**：$\log_b x=\dfrac{\ln x}{\ln b}$。所以底选谁**不影响最优解的位置**，只影响损失的数值和单位（nats vs bits）。
- 既然不影响结果，全行业就统一选"公式最短"的那个：$e$。
- **一句话**：$e$ 不是神秘常数，是"让微积分不用带一堆常数因子"的那个底。

---

### 9. 数值稳定：工程上真正会踩的坑

| 现象                   | 原因                                                                 | 解决                                                            |
| ---------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------- |
| `exp` 溢出成 `inf` | $e^{1000}\approx10^{434}$，超过 float64 上限 $1.8\times10^{308}$ | 先减去最大值：$\text{softmax}(z)=\text{softmax}(z-\max z)$    |
| 概率连乘变成 0         | $0.01^{1000}$ 下溢                                                 | 全程在对数域相加（log-space）                                   |
| `log(0) = -inf`      | 概率被算成精确 0                                                     | clip 到 $[10^{-7},1-10^{-7}]$，或用 `log_softmax`           |
| 损失是 `nan`         | $0\times\log0$ 或 $-\infty+\infty$                               | 用框架自带的 `CrossEntropyLoss` / `log_softmax`，不要自己拼 |

- 这就是著名的 **log-sum-exp trick**：先减去最大值再取 $\exp$，数学上完全等价，数值上不会溢出。
- 记住一句：**"先 $\log$，再相加，最后才 $\exp$ 回去"** —— 几乎所有工业级实现都遵守这个顺序。

---

### 10. 易错点 / 考点

1. **$\exp(x)$ 与 $e^x$ 完全同义**，不是两种运算；`exp` 只是函数写法。
2. **ML 里的 $\log$ 默认是 $\ln$**，不是 $\log_{10}$；看到 CE 的数值要有"nats"的意识。
3. **$\log(a+b)\neq\log a+\log b$**，只有乘法才能拆。这是最高频的代数错误。
4. **$\log$ 不改变谁大谁小**，所以可以放心对目标函数取 $\log$ 再优化；但**会改变数值大小**，不能拿来比较不同定义的损失。
5. **$e$ 不是"为了让公式好看硬塞的"**：它来自"增长率正比于自身"这类过程，以及导数的唯一性。
6. **Softmax 对整体平移不变**：$z+c$ 结果不变，所以 logits 的绝对值没有意义，只有差值有意义。
7. **Sigmoid 两端会饱和**：$z=\pm10$ 时导数已经接近 0，这是梯度消失的来源，不是 bug 是形状决定的。
8. **别把 CE 的数值当准确率**：CE 是概率质量的对数惩罚，和"对了几题"不是一回事。

---

### 11. 与课程的联系

- **L2 P10**：Sigmoid 与 logit 就是"线性打分 + $\log$ 反解"的产物；CE 是它的配套损失。
- **L3**：语言模型对下一个 token 做多分类，损失是 CE；Perplexity $=e^{\text{CE}}$ 就是这里讲的 $e$ 与 $\log$ 的直接应用。
- **L4**：注意力里的 Softmax 同样是 $e^{z}/\sum e^{z}$，还要用 log-sum-exp 保稳定。
- 复习口诀：**$e$ 造概率（加 → 乘），$\log$ 造损失（乘 → 加），两者互为反函数。**

## Q3. Sigmoid 和 logit 是什么？

**问题原话**：「Sigmoid 和 logit 是什么」

**一句话答案**：Sigmoid 是"把任意打分压成 0–1 概率"的 S 形函数；logit 是它的**反函数**，把概率变回"对数几率"，而在这个尺度上线性分类器的打分正好是直线 $w^Tx$。

### 1. 先看它们要解决什么问题

- 线性分类器只会算一个分：$z=w^Tx+b$，可以是 $-7$、$0.3$、$52$。
- 但我们要的是"属于类 1 的概率"，必须在 $(0,1)$ 里。
- 于是需要一座桥：**实数 $\leftrightarrow$ 概率**。
- Sigmoid 走"实数 → 概率"；logit 走"概率 → 实数"。方向相反，同一座桥。

### 2. Sigmoid：把打分压成概率

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

**符号解释 / 直觉**

| 符号         | 是什么               | 在干嘛                 |
| ------------ | -------------------- | ---------------------- |
| $z$        | 线性打分 $w^Tx+b$  | 可正可负、可大可小     |
| $e^{-z}$   | 指数函数             | $z$ 越大，它越接近 0 |
| $1+e^{-z}$ | 正数，且 $\ge 1$   | 保证分母不会太小       |
| 整体         | 分子 1、分母略大于 1 | 输出被夹在 $(0,1)$   |

- 形状：$z$ 从小变大，输出从 0 平滑升到 1，中间过 $0.5$。
- 三个锚点：

| $z$  | $\sigma(z)$ | 读法         |
| ------ | ------------- | ------------ |
| $-5$ | $0.0067$    | 几乎断定类 0 |
| $0$  | $0.5$       | 完全拿不准   |
| $+5$ | $0.9933$    | 几乎断定类 1 |

- 两个好用的性质：
  - 单调递增：谁分高谁概率大，不会乱序。
  - 对称：$1-\sigma(z)=\sigma(-z)$，两类概率天然互补。

### 3. Logit：把概率变回打分

$$
\operatorname{logit}(p)=\log\frac{p}{1-p}
$$

**符号解释 / 直觉**

- $p$：模型给"类 1"的概率。
- $1-p$：给"类 0"的概率。
- $\dfrac{p}{1-p}$ 叫 **Odds（几率）**：类 1 的机会是类 0 的几倍。
- 外面再套 $\log$：把"倍数"变成可加减的尺度，值域铺满整个实数轴。

**它俩是反函数**（这是最该记住的一句）：

$$
\operatorname{logit}\big(\sigma(z)\big)=z,\qquad \sigma\big(\operatorname{logit}(p)\big)=p
$$

- 所以 P10 那句 $\log\dfrac{p}{1-p}=w^Tx$ 的意思只是：**"把 Sigmoid 反解回去，右边就剩线性打分"**。
- 这也解释了"线性分类器"这个名字：**对数几率**是 $x$ 的线性函数。

### 4. 手算两个方向

**正向**：$z=1.5$

$$
e^{-1.5}\approx0.223,\qquad \sigma(1.5)=\frac{1}{1+0.223}\approx0.818
$$

- 读法：这个样本约 82% 属于类 1。

**反向**：$p=0.8$

$$
\text{odds}=\frac{0.8}{0.2}=4,\qquad \operatorname{logit}(0.8)=\ln 4\approx1.386
$$

- 读法：类 1 的机会是类 0 的 4 倍；换成打分就是 $1.386$。
- 验证互逆：$\sigma(1.386)=\dfrac{1}{1+e^{-1.386}}=\dfrac{1}{1+0.25}=0.8$ ✅

| $p$ | odds $=\frac{p}{1-p}$ | logit $=\ln$ odds |
| ----- | ----------------------- | ------------------- |
| 0.5   | 1                       | 0                   |
| 0.8   | 4                       | 1.386               |
| 0.9   | 9                       | 2.197               |
| 0.99  | 99                      | 4.595               |

- 注意：$p$ 从 0.9 到 0.99 只涨 0.09，logit 却从 2.2 涨到 4.6 —— 越接近 1，越难再涨，所以需要"拉伸"。

### 5. 为什么 logit 一出现，边界就必然是直线

- 模型假设：$\operatorname{logit}(p)=w^Tx+b$。
- 决策规则是 $p>0.5$：
  - $p>0.5 \iff \dfrac{p}{1-p}>1 \iff \log\dfrac{p}{1-p}>0$。
- 代进去：$w^Tx+b>0$。
- 于是"概率过半"这条规则，等价于"点在超平面 $w^Tx+b=0$ 的正侧"。
- 换句话说：**边界之所以是直线，不是画出来的，是 logit 线性假设推出来的。**

### 6. 易错点 / 考点

1. **logit 不是 Sigmoid 的倒数**：倒数是 $1/\sigma=1+e^{-z}$；logit 是**反函数** $\sigma^{-1}$。
2. **ML 里的 $\log$ 是 $\ln$**：logit 的单位常叫"log-odds"，底数取 $e$。
3. **Sigmoid 不是分类器**：它只输出概率，分类还要加阈值（0.5）这一步。
4. **$p=0$ 或 $p=1$ 时 logit 是 $\pm\infty$**：所以代码里要给概率 clip 一下，否则 log 爆掉。
5. **Sigmoid 两端饱和**：$z=\pm10$ 时导数接近 0，梯度消失是形状决定的，不是实现 bug。
6. **概率是模型假设，不是真理**：Sigmoid 输出 0.9，只代表"在这个模型下"是 90%，校准（calibration）是另一回事。
7. **二分类 Softmax 会退化成 Sigmoid**：两类时 $\dfrac{e^{z_1}}{e^{z_1}+e^{z_2}}=\sigma(z_1-z_2)$，所以两者不矛盾。

### 7. 与课程的联系

- **L2 P10–P11**：$\sigma$ 负责"打分 → 概率"，logit 负责"概率 → 线性"，决策规则 $p>0.5\iff w^Tx>0$ 全靠这对互逆关系。
- **L2 Q1**：Sigmoid + Cross-Entropy 是配套的；CE 对打分的导数恰好是 $\sigma(z)-y$，非常干净。
- **L3 / L4**：多类时 Sigmoid 换成 Softmax，logit 变成"未归一化的打分向量"（代码里 `logits` 就是这个名字的来源）。

## Q4. $\hat y=\arg\max_k p(y=k|x)$ 怎么读？$\hat y$ 是什么？它和线性分类器什么关系？

**问题原话**：「Classification: Decision Rule 里 $\hat y=\arg\max_k p(y=k|x)$ 和 hat y 什么意思。我理解了 Linear Classification，这两个之间什么关系我没看懂」

**一句话答案**：$\hat y$ 是"模型最终报出的预测类别"；整句读作"在所有类别 $k$ 里，挑出让 $p(y=k|x)$ 最大的那个 $k$"；线性分类器只负责**打分**，argmax 才是最后**选一个类**的那一步。

### 1. 先拆 $\hat y$

| 符号            | 读法               | 是什么                              |
| --------------- | ------------------ | ----------------------------------- |
| $y$           | 真值 label（标签） | 数据里给定的标准答案（0/1 或类号）  |
| $\hat y$      | y-hat，预测值      | 模型算出来的答案                    |
| 帽子 $\hat{}$ | "估计"             | 带帽子就表示"猜的 / 估的"，不是真的 |

- 回归里 $\hat y$ 是一个数（例如房价 320 万）。
- 分类里 $\hat y$ 是一个**类号**（0、1、2…）。
- 它既不是概率、也不是参数、更不是损失，就是一句"最终答案"。

### 2. 再拆 $\arg\max_k$

- $\max_k f(k)$：所有类里**最大的那个数值**。
- $\arg\max_k f(k)$：取得最大值的那个**下标 $k$**。

| 例子                    | $\max$ | $\arg\max$       |
| ----------------------- | -------- | ------------------ |
| $f=(0.1,\ 0.7,\ 0.2)$ | $0.7$  | $2$（按从 1 数） |
| $f=(0.82,\ 0.18)$     | $0.82$ | 类 1               |

- 一句话：**max 要分数，argmax 要名次。**

### 3. 整句怎么读

$$
\hat y=\arg\max_k p(y=k|x)
$$

- 逐符号：
  - $x$：这一条样本（特征向量）。
  - $k$：类别编号，遍历所有类；二分类 $k\in\{0,1\}$，三分类 $k\in\{1,2,3\}$。
  - $p(y=k|x)$：模型认为"给定 $x$，它属于类 $k$"的概率。
  - $\arg\max_k$：把所有 $k$ 的概率比一遍，返回概率最大的那个 $k$。
  - $\hat y$：返回的这个 $k$，就是最终预测。
- 人话版：**"每类概率都算出来，谁最高就报谁。"**

### 4. 它和线性分类器的关系（关键）

线性分类器只做"打分"，决策规则才做"选类"。串起来是三步：

$$
x\ \longrightarrow\ z_k=w_k^Tx+b_k\ \longrightarrow\ p(y=k|x)\ \longrightarrow\ \hat y=\arg\max_k p(y=k|x)
$$

| 步骤      | 谁负责                             | 输出               |
| --------- | ---------------------------------- | ------------------ |
| ① 打分   | Linear Classifier（线性分类器）    | 任意实数 $z_k$   |
| ② 变概率 | Sigmoid（二分类）/ Softmax（多类） | $(0,1)$ 且和为 1 |
| ③ 选类   | Decision Rule（决策规则，argmax）  | 类号 $\hat y$    |

- **"线性"只形容第①步**：分数是 $x$ 的线性函数。
- **"分类"发生在第③步**：argmax 把连续概率变成离散类号。
- 所以"线性分类器" = 线性打分 + 一个 argmax；缺了 argmax 它只是个打分器。

### 5. 二分类：argmax 退化成"看 0.5"

- 两类只有 $p(y=1|x)$ 和 $p(y=0|x)=1-p(y=1|x)$，两者相加为 1。
- 比大小等价于看谁超过一半：

$$
\hat y=\arg\max\{p,\ 1-p\}=
\begin{cases}
1, & p>0.5\\
0, & p<0.5
\end{cases}
$$

- 再用 Sigmoid 单调性：$p>0.5 \iff \sigma(w^Tx)>0.5 \iff w^Tx>0$。
- 这就是 P11 的 "$\hat y=1$ iff $w^Tx>0$"：**argmax → 阈值 0.5 → 超平面正侧**，三步是同一件事。

### 6. 多分类：argmax 在切"决策区域"

- 每类一条直线打分：$g_k(x)=w_k^Tx+b_k$。
- $\hat y=\arg\max_k g_k(x)$；对概率取 argmax 与对分数取 argmax 结果相同（Softmax 保序）。
- 两类打平时 $g_i(x)=g_j(x)$，就是它们之间的分界线。
- 三类的边界两两相交，把平面切成三块 —— 这就是 P12 的 Decision Region（决策区域）。

### 7. 手算两个

**二分类**：$w=(2,-1)$、$b=0.5$、$x=(1,1)$

$$
z=2\times1+(-1)\times1+0.5=1.5,\quad p_1=\sigma(1.5)\approx0.818,\quad p_0=0.182
$$

- $\arg\max\{0.818,\ 0.182\}=1$，所以 $\hat y=1$。

**三分类**：打分 $z=(2,\ 0.5,\ -1)$

$$
e^{2}=7.389,\quad e^{0.5}=1.649,\quad e^{-1}=0.368,\quad \text{和}=9.406
$$

$$
p=\left(\frac{7.389}{9.406},\ \frac{1.649}{9.406},\ \frac{0.368}{9.406}\right)=(0.786,\ 0.175,\ 0.039)
$$

- 最大是 0.786 → $\hat y=1$。
- 若类别名是（猫、狗、鹿），则预测"猫"。

### 8. 代码里就是这一行

| 场景    | 代码                            | 返回什么        |
| ------- | ------------------------------- | --------------- |
| NumPy   | `np.argmax(probs)`            | 概率最大的下标  |
| PyTorch | `torch.argmax(logits, dim=1)` | 每个样本的类号  |
| sklearn | `clf.predict(X)`              | 内部就是 argmax |
| 看概率  | `clf.predict_proba(X)`        | 各类概率        |

- `predict()` 只给答案，`predict_proba()` 才给概率；考试问"模型输出什么"要分清。

### 9. 为什么训练时不用 argmax

- argmax 是**阶跃**操作：概率微动，输出要么不变、要么突然跳一类。
- 它几乎处处导数为 0，给不出梯度 → 不能拿来训练。
- 所以：**训练用概率 + Cross-Entropy（可导）；预测用 argmax（不可导，但正是我们要的答案）。**
- 一句话：**argmax 是交卷，CE 是平时刷题。**

### 10. 易错点 / 考点

1. **$\hat y$ 不是概率**：概率是 $p$，$\hat y$ 是类号。
2. **argmax 返回下标，不是最大值**；别把 0.786 当成 $\hat y$。
3. **$k$ 的起点看约定**：数学常从 1 数，代码从 0 数，别混。
4. **平局要有规则**：实现一般取最小下标；考试若出并列会另说明。
5. **对概率 argmax = 对分数 argmax**（Sigmoid / Softmax 保序），所以框架直接对 logits 取 argmax，省一次 $\exp$。
6. **"最优贝叶斯分类器"是理想版**：那要求 $p$ 是真实后验；我们用的是模型估的 $p$，属于 plug-in 规则（见 P11 的 ⚠️）。
7. **二分类别只跟 0 比**：只算 $p_1$ 时，比较对象是 $1-p_1$，不是 0。

### 11. 与课程的联系

- **P10**：线性打分 + Sigmoid → 得到概率 $p$。
- **P11**：argmax → 得到 $\hat y$；二分类退化成 $p>0.5 \iff w^Tx>0$。
- **P12**：多类 argmax 的几何后果就是决策区域。
- **L1**：KNN 的"多数投票"本质就是 argmax（对类别计数取最大）。
- **L3**：语言模型对词表做 argmax 就是贪心解码，只是实际常用采样代替。

## Q5. 三分类是不是不用 Sigmoid 改用 Softmax？B2 / B3 太抽象，能给例题吗？

**问题原话**：「所以三分类是不是就不需要 sigmoid，使用 softmax？我看完了 B2 和 B3，但感觉还是太抽象了，请举几个例题来解释他们」

**一句话答案**：三类**互斥**（一张图只能是猫/狗/鹿之一）时，要概率就用 Softmax，Sigmoid 不再合适；但**只做分类**时可以直接对分数 argmax，连 Softmax 都能省。多标签（可同时是猫和狗）才继续用**每类一个 Sigmoid**。

### 1. 三种输出层怎么选

| 场景                      | 输出层                       | 输出之和 | 例子                |
| ------------------------- | ---------------------------- | -------- | ------------------- |
| 二分类（互斥）            | Sigmoid，1 个数              | —       | 垃圾邮件 / 正常邮件 |
| 多分类（互斥，$K\ge3$） | Softmax，$K$ 个数          | $=1$   | 猫 / 狗 / 鹿        |
| 多标签（不互斥）          | 每类一个 Sigmoid，$K$ 个数 | 不必为 1 | 图中同时有猫和狗    |

- 互斥用 Softmax：它把"谁分高"变成"分掉 100% 的信任"。
- 多标签不能用 Softmax：概率总和为 1 等于"只能选一个"。

### 2. 先记住一条：Softmax 保序，所以 argmax 不变

$$
\text{softmax}(z)_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

- $e^{z}$ 单调递增 → 打分最高的类，Softmax 后仍最高。
- 所以 **对分数 argmax = 对概率 argmax**，分类结果完全一样。
- 推论：B3 直接对 $g_k$ 取 argmax 是对的；Softmax 只在"要概率"或"算 CE"时必须。

### 3. 例题 1（B2）：二分类四个点，一路算到预测

设 $w=(1,1)$、$b=-2$，即 $z=x_1+x_2-2$。

| 点 $x$      | $z$  | $p=\sigma(z)$ | $\hat y$ | CE（真值 $y$）             |
| ------------- | ------ | --------------- | ---------- | ---------------------------- |
| $(0,0)$     | $-2$ | $0.119$       | 0          | $y=0$：$-\ln0.881=0.127$ |
| $(0.5,0.5)$ | $-1$ | $0.269$       | 0          | $y=0$：$-\ln0.731=0.313$ |
| $(1,2)$     | $1$  | $0.731$       | 1          | $y=1$：$-\ln0.731=0.313$ |
| $(2,2)$     | $2$  | $0.881$       | 1          | $y=1$：$-\ln0.881=0.127$ |

- 决策边界：$x_1+x_2-2=0$，即 $x_2=2-x_1$（45° 斜线）。
- 线上方（$z>0$）判 1，下方判 0。
- 观察最后一列：**同样 $p=0.731$，真值反了，损失从 0.313 跳到 1.313**（$-\ln0.269$）。

### 4. 例题 2（B2）：押错大注，罚多重

接上，点 $(1,2)$ 的 $p=0.731$：

- 真值 $y=1$：$L=-\ln0.731=0.313$，罚得轻。
- 真值 $y=0$：$L=-\ln(1-0.731)=-\ln0.269=1.313$，罚得重。
- 直觉：模型把 73% 的注押在"1"上，答案却是 0 → 押错大注，罚 1.31。

### 5. 例题 3（B3）：三分类打分 + argmax，不碰概率

三个类各一条直线：

$$
g_1=x_1+x_2-1\ (\text{猫}),\qquad g_2=x_1-x_2\ (\text{狗}),\qquad g_3=1-x_1\ (\text{鹿})
$$

| 点 $x$   | $g_1$ | $g_2$ | $g_3$ | $\arg\max$ |
| ---------- | ------- | ------- | ------- | ------------ |
| $(2,1)$  | $2$   | $1$   | $-1$  | 猫           |
| $(3,0)$  | $2$   | $3$   | $-2$  | 狗           |
| $(0,0)$  | $-1$  | $0$   | $1$   | 鹿           |
| $(1,2)$  | $2$   | $-1$  | $0$   | 猫           |
| $(-2,2)$ | $-1$  | $-4$  | $3$   | 鹿           |
| $(1,-1)$ | $-1$  | $2$   | $0$   | 狗           |

- 这里**完全没有 Sigmoid / Softmax**，照样分类。
- B3 的本质：分类 = 比大小，几何 = 切区域。

### 6. 例题 4（B2 与 B3 的交汇）：把上表分数变概率

以 $(2,1)$ 的分数 $z=(2,\ 1,\ -1)$ 为例：

$$
e^{2}=7.389,\quad e^{1}=2.718,\quad e^{-1}=0.368,\quad \text{和}=10.475
$$

$$
p=\left(\frac{7.389}{10.475},\ \frac{2.718}{10.475},\ \frac{0.368}{10.475}\right)=(0.705,\ 0.260,\ 0.035)
$$

- $\hat y=\arg\max p=1$（猫），与例题 3 一致。
- CE（真值猫）：$-\ln0.705=0.349$。
- 两个检查：
  - $\dfrac{p_1}{p_2}=\dfrac{0.705}{0.260}=2.72=e^{2-1}$ —— 分数差 1，概率差 $e$ 倍。
  - 三个分数同时加 100，概率不变（平移不变）。

### 7. 例题 5：三分类用 Sigmoid 会"不合一"

同样分数 $(2,1,-1)$，对每类各套 Sigmoid：

| 类   | $z_k$ | $\sigma(z_k)$ |
| ---- | ------- | --------------- |
| 猫   | $2$   | $0.881$       |
| 狗   | $1$   | $0.731$       |
| 鹿   | $-1$  | $0.269$       |
| 合计 | —      | $1.881\neq1$  |

- 三个数都像概率，加起来 1.88，解释不通。
- 原因：Sigmoid 假设每类**独立**；互斥类别不独立。
- 但 argmax 仍是猫 → **只求分类结果时两者等价**，差别在概率解释与 CE。

### 8. 例题 6：什么时候必须回到 Sigmoid（多标签）

一张图同时有猫和狗，分数（猫 2.0，狗 1.5）：

| 方案         | 猫        | 狗        | 结论                 |
| ------------ | --------- | --------- | -------------------- |
| 每类 Sigmoid | $0.881$ | $0.818$ | 都 >0.5 → 都出现 ✅ |
| Softmax      | $0.622$ | $0.378$ | 只能选猫 ❌          |

- 判断标准不是"几类"，而是**能不能同时成立**。

### 9. 例题 7（B3）：把决策区域真的算出来

用例题 3 的三个 $g$，边界是两两相等：

$$
g_1=g_2:\ x_2=0.5,\qquad g_1=g_3:\ x_2=2-2x_1,\qquad g_2=g_3:\ x_2=2x_1-1
$$

- $\mathcal{R}_1$（猫）：$x_2>0.5$ 且 $x_2>2-2x_1$。
- $\mathcal{R}_2$（狗）：$x_2<0.5$ 且 $x_2<2x_1-1$。
- $\mathcal{R}_3$（鹿）：$x_2<2-2x_1$ 且 $x_2>2x_1-1$。

验算：$(2,1)$ 满足 $\mathcal{R}_1$ 两条 ✅；$(0,0)$ 满足 $\mathcal{R}_3$ 两条（$0<2$、$0>-1$）✅。

- 三条直线把平面切成三块，**没有"其他"区域**：argmax 一定给答案。
- 分界线上 $g_i=g_j$，模型"打平"；实现时通常取小下标。

### 10. 二分类其实是 Softmax 的特例

$$
\text{softmax}\big((z,0)\big)=\frac{e^{z}}{e^{z}+1}=\frac{1}{1+e^{-z}}=\sigma(z)
$$

- 更一般：两类时 $p_1=\sigma(z_1-z_2)$，**只有分数差有用**。
- 所以"二分类 Sigmoid、多分类 Softmax"不是两套理论，是同一套的两种写法。

### 11. 一张表收尾

| 你的目的             | 该做什么                              |
| -------------------- | ------------------------------------- |
| 只要类号             | 对 $g_k(x)$ 取 argmax，Softmax 可省 |
| 要概率（互斥）       | Softmax                               |
| 要训练（互斥）       | Softmax + CE                          |
| 要概率（可同时多个） | 每类 Sigmoid + 各自阈值               |
| 二分类               | Sigmoid（= 2 类 Softmax）             |

### 12. 易错点 / 考点

1. **"三类就必须 Softmax"不完全对**：只分类时 argmax 打分即可；Softmax 是为概率和 CE。
2. **Sigmoid 各算各的、和不为 1**，不代表错，只代表它假设"独立"。
3. **Softmax 不改变 argmax**，所以框架里可直接对 logits 取 argmax。
4. **多标签不是多分类**：看"能否同时成立"，而不是"有几个类"。
5. **平移不变**：$z+c$ 概率不变，logits 的绝对值无意义。
6. **数值稳定**：先减最大值再 $\exp$（见 Q2 第 9 节）。
7. **多类 CE 只罚正确类**：$L=-\ln p_{\text{正确类}}$。

### 13. 与课程的联系

- **P10**：二分类 $p=\sigma(w^Tx)$。
- **P11**：argmax 变类号（见 Q4）。
- **P12**：多类 $g_k$ 的 argmax = 决策区域；Softmax 只是概率版，边界不变（notes 已标为拓展）。
- **L4**：注意力权重也是 Softmax，同一套公式。

## Q6. Softmax、保序、类号、CE、MSE 各是什么？彼此什么关系？属分类还是回归？

**问题原话**：「请你再仔细地为我解释一下什么是 softmax，保序是什么、类号是什么、ce 是什么、和 mse 是不是也有关系，这些概念之间都是什么关系，这些是分类还是线性回归。然后能不能通过 1、2 个例子为我串联起来」

**一句话答案**：一条链串起来 —— **线性打分 $z=Wx+b$ → Softmax / Sigmoid → 概率 $p$ → CE 算损失；预测时 argmax 把概率变回类号**。MSE 是**回归**那条平行链上的损失；它和 CE 是"同门兄弟"——都是负对数似然（NLL），只是假设的分布不同。

### 1. 五个词，各一句话

| 概念    | 一句话                               | 属于哪一步       | 任务 |
| ------- | ------------------------------------ | ---------------- | ---- |
| Softmax | 把 $K$ 个任意分数变成和为 1 的概率 | 打分 → 概率     | 分类 |
| 保序    | 变换前后谁大谁小的顺序不变           | 性质（不是模块） | 通用 |
| 类号    | 类别的整数编号，只是"名字的编号"     | 预测输出         | 分类 |
| CE      | 只罚"给正确答案的概率太低"的损失     | 概率 → 损失     | 分类 |
| MSE     | 预测值与真值之差的平方平均           | 数值 → 损失     | 回归 |

- 一句话记：**Softmax 造概率，保序保证不改变冠军，argmax 报类号，CE 罚分类错误，MSE 罚数值偏差。**

### 2. 类号（class index）：它只是"名字的编号"

| 类别 | 数学写法 $k$ | 代码下标 | One-Hot 向量 |
| ---- | -------------- | -------- | ------------ |
| 猫   | 1              | 0        | $(1,0,0)$  |
| 狗   | 2              | 1        | $(0,1,0)$  |
| 鹿   | 3              | 2        | $(0,0,1)$  |

- **它没有大小含义**：不能说"鹿（3）比猫（1）大"，也不能对类号求平均。
- 数学教材常从 1 数，代码（NumPy / PyTorch）从 0 数；差一个 1，别混。
- One-Hot 的作用：把"第几个类"变成"挑出第几个概率" —— $p_{\text{正确类}}=\sum_k y_k p_k$。
- $\hat y$ 的取值就是类号，例如 $\hat y=1$（数学）= 代码下标 0 = 猫。

> ⚠️ 常见错误：把类号当连续值做回归（例如"猫=1、狗=2、鹿=3，预测 1.5 就是猫狗之间"）—— 没有这种中间类。

### 3. Softmax：把分数变成"分蛋糕"

$$
\text{softmax}(z)_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
$$

- 逐符号：
  - $z_k$：第 $k$ 类的分数（logit），可正可负。
  - $e^{z_k}$：先变成正数。
  - 分母 $\sum_j e^{z_j}$：所有类的"正数"总和。
  - 输出 $p_k$：第 $k$ 类分到的比例。
- 三条性质：

| 性质 | 含义                 |
| ---- | -------------------- |
| 非负 | 每个 $p_k>0$       |
| 归一 | $\sum_k p_k=1$     |
| 保序 | 分数高的类，概率也高 |

- **为什么用 $e$**：$e^{a}/e^{b}=e^{a-b}$，把"分数差"变成"倍数"；同时 $e^x$ 恒正、单调、求导还是自己（详见 Q2）。
- 手算 $z=(2,1,-1)$：

$$
e^2=7.389,\quad e^1=2.718,\quad e^{-1}=0.368,\quad \text{和}=10.475
$$

$$
p=(0.705,\ 0.260,\ 0.035)
$$

- **平移不变**：$z$ 全部加 100，概率不变（分子分母同乘 $e^{100}$）。
- **只有差值有意义**：$p_i/p_j=e^{z_i-z_j}$。
- **Softmax 不是分类器**：它只输出概率，选类还要 argmax。

### 4. 保序（order-preserving）：换衣服，不换名次

- 定义：若 $f$ 单调递增，则 $z_i>z_j \Rightarrow f(z_i)>f(z_j)$。
- Softmax 保序的写法：

$$
\frac{p_i}{p_j}=e^{z_i-z_j}
$$

- $z_i-z_j$ 变大 → 比值变大 → 排名不变。
- 三个直接后果：

| 后果        | 说明                          |
| ----------- | ----------------------------- |
| argmax 不变 | 对分数 argmax = 对概率 argmax |
| 平局不变    | $z_i=z_j$ → $p_i=p_j$    |
| 数值会变    | 概率不是分数本身，别混着比较  |

- 演示：$z=(2,1,-1)\to p=(0.705,0.260,0.035)$；把猫狗分数对调 $z=(1,2,-1)\to p=(0.260,0.705,0.035)$ —— **名次跟着分数走，数值整体重排**。
- 反例（不保序）：$1-p$、$p^2$ 都会改变大小关系，所以不能拿它们当"另一种概率"来 argmax。
- 这就是为什么代码里可以直接 `argmax(logits)`：省掉 Softmax 也不影响预测。

### 5. CE（Cross-Entropy）：只罚"给正确答案的概率"

$$
L=-\sum_{k=1}^{K}y_k\ln p_k
$$

- 逐符号：
  - $y_k$：One-Hot 真值，只有正确类是 1。
  - $p_k$：模型给第 $k$ 类的概率。
  - $\ln$：概率越接近 0，$-\ln$ 越大 → 罚得越狠。
- One-Hot 让求和只剩一项：

$$
L=-\ln p_{\text{正确类}}
$$

- 数值感受（真值固定为类 1）：

| $p_{\text{正确}}$ | CE    | 读法         |
| ------------------- | ----- | ------------ |
| 0.99                | 0.010 | 几乎不罚     |
| 0.90                | 0.105 | 很轻         |
| 0.50                | 0.693 | 罚一次"ln 2" |
| 0.10                | 2.303 | 重罚         |
| 0.01                | 4.605 | 极重罚       |

- CE 衡量的是"概率质量"而不是"对了几题"：准确率 90% 的模型，CE 可能仍然很高。
- 与熵的关系：CE = 熵 + KL 散度；模型越接近真实分布，CE 越接近熵（详见 Q1）。

### 6. MSE：回归的损失，和 CE 是"同门兄弟"

$$
\text{MSE}=\frac1n\sum_{i=1}^{n}(y_i-\hat y_i)^2
$$

- 逐符号：$y_i$ 真值，$\hat y_i$ 预测，$n$ 样本数；先残差、再平方、再平均。
- 同一个 $p$（真值 $y=1$）下，CE 与 MSE 的对比：

| $p$ | CE $=-\ln p$ | MSE $=(1-p)^2$ |
| ----- | -------------- | ---------------- |
| 0.99  | 0.010          | 0.0001           |
| 0.90  | 0.105          | 0.010            |
| 0.50  | 0.693          | 0.250            |
| 0.10  | 2.303          | 0.810            |
| 0.01  | 4.605          | 0.980            |

- MSE 有上界（二分类最多 1），CE 无上界 → **越自信地答错，CE 罚得越狠**。
- 深层关系（结论，不用推导）：

| 损失         | 等价于哪种分布的负对数似然 |
| ------------ | -------------------------- |
| MSE          | 高斯（正态）分布，方差固定 |
| CE（二分类） | 伯努利分布                 |
| CE（多分类） | 类别（Categorical）分布    |

- 所以"回归用 MSE、分类用 CE"不是拍脑袋，而是**你对 $y$ 的分布假设**决定的：$y$ 连续 → 高斯 → MSE；$y$ 是 0/1 或类号 → 伯努利/类别 → CE。
- 为什么分类不用 MSE（三条）：
  1. MSE 对"自信答错"惩罚不够（0.01 与 4.6 的差别）。
  2. 与 Sigmoid 搭配时梯度会被 $p(1-p)$ 拖小，两端几乎学不动。
  3. 损失曲面不凸，训练更不稳（超纲，只需记住结论）。

### 7. 这些到底是分类还是回归？

| 名称                                              | 任务           | 输出                                | 损失      | 决策       |
| ------------------------------------------------- | -------------- | ----------------------------------- | --------- | ---------- |
| Linear Regression（线性回归）                     | 回归           | 连续数值 $\hat y=w^Tx+b$          | MSE       | 不需要阈值 |
| Logistic Regression（逻辑回归）                   | **分类** | 概率 $p=\sigma(w^Tx)$             | CE（BCE） | $p>0.5$  |
| Softmax Regression（Softmax 回归 / 多类逻辑回归） | **分类** | 概率向量 $p=\text{softmax}(Wx+b)$ | CE        | argmax     |

- **名字陷阱**：Logistic / Softmax **Regression** 里虽然有 regression，任务却是分类；"回归"在这里指"用线性模型算一个连续打分"。
- **"线性"修饰的是打分**：$z=Wx+b$ 对 $x$ 线性；后面的 Sigmoid / Softmax / argmax 都不是线性的。
- 一根链条上的归属：

```
分类分支：x → z=Wx+b → Sigmoid/Softmax → p → CE → 训练
                                        ↘ argmax → ŷ（类号）

回归分支：x → z=Wx+b → ŷ（直接用） → MSE → 训练
```

- 一句话：**Softmax、保序、类号、argmax、CE 都是分类侧的；MSE 是回归侧的；两者共用一个线性打分器。**

### 8. 例子 1：二分类垃圾邮件（把所有概念串一遍）

设 $z=w^Tx+b=1.5$。

| 步骤              | 计算                                   | 结果                     |
| ----------------- | -------------------------------------- | ------------------------ |
| ① 打分           | $z=1.5$                              | 1.5                      |
| ② 变概率         | $p=\sigma(1.5)=\frac{1}{1+e^{-1.5}}$ | $0.818$                |
| ③ 决策           | $p>0.5$                              | $\hat y=1$（垃圾邮件） |
| ④ 损失（真值 1） | $-\ln0.818$                          | $0.201$                |
| ⑤ 若真值是 0     | $-\ln(1-0.818)$                      | $1.704$                |

- 类号：$0$=正常邮件，$1$=垃圾邮件；$\hat y$ 就是这个编号。
- 对比 MSE：真值 1 时 $(1-0.818)^2=0.033$；真值 0 时 $(0-0.818)^2=0.669 —— 两者都在罚，但 CE 对"答错"更敏感。
- 保序在这里的作用：$\sigma$ 单调，所以"$p>0.5$"与"$z>0$"是同一刀，决策边界才能写成 $w^Tx+b=0$。

### 9. 例子 2：三分类 + 与回归对照（完整闭环）

三个类打分：

$$
g_1=x_1+x_2-1\ (\text{猫}),\quad g_2=x_1-x_2\ (\text{狗}),\quad g_3=1-x_1\ (\text{鹿})
$$

取 $x=(2,1)$：

| 步骤            | 计算                                            | 结果                        |
| --------------- | ----------------------------------------------- | --------------------------- |
| ① 打分         | $g=(2,\ 1,\ -1)$                              | $(2,1,-1)$                |
| ② Softmax      | $e^z=(7.389,\ 2.718,\ 0.368)$，和 $=10.475$ | $(0.705,\ 0.260,\ 0.035)$ |
| ③ argmax       | 最大是第 1 项                                   | $\hat y=1$（猫）          |
| ④ CE（真值猫） | $-\ln0.705$                                   | $0.349$                   |
| ⑤ 若真值是狗   | $-\ln0.260$                                   | $1.347$                   |

- 保序检查：$g_1>g_2>g_3$，对应 $p_1>p_2>p_3$ ✅。
- 平移检查：$g$ 加 $(10,10,10)$，$p$ 不变 ✅。
- 与回归对照：如果这是"预测猫的体重"，就**不要** Softmax、不要类号；直接 $\hat y=w^Tx+b=3.2$ kg，损失用 MSE。
- 同一个 $z=Wx+b$：接 Softmax + CE 就是分类，接 MSE 就是回归 —— **区别在"输出怎么解释"和"损失怎么罚"**。

### 10. 概念依赖图（谁用到谁）

| 概念     | 输入              | 输出            | 被谁使用                   |
| -------- | ----------------- | --------------- | -------------------------- |
| 线性打分 | $x$             | $z$           | Softmax / Sigmoid / argmax |
| Sigmoid  | $z$             | $p$（1 个数） | 二分类 CE、阈值决策        |
| Softmax  | $z$（$K$ 个） | $p$（和为 1） | 多类 CE、argmax            |
| argmax   | $z$ 或 $p$    | 类号 $\hat y$ | 预测                       |
| CE       | $p$ + 真值类号  | 标量损失        | 反向传播                   |
| MSE      | $\hat y$ + 真值 | 标量损失        | 反向传播                   |

### 11. 易错点 / 考点

1. **Softmax 不是分类器**，它只造概率；分类靠 argmax。
2. **保序 ≠ 数值不变**：名次不变，概率值会变。
3. **类号没有大小**，不能求平均、不能当回归目标。
4. **CE 不是准确率**：CE 罚概率质量，准确率只数对错。
5. **MSE 与 CE 不可直接比大小**：量纲不同；只在同一损失内比较。
6. **二分类 Softmax = Sigmoid**：$p_1=\sigma(z_1-z_2)$，不是两套东西。
7. **多标签用 Sigmoid + BCE**，不是 Softmax。
8. **"逻辑回归"是分类**；"线性回归"才是回归。
9. **logits 是 Softmax 的输入**：框架里 `logits` 就是未归一化的 $z$。

### 12. 与课程的联系

- **L1**：线性回归 + MSE + 梯度下降是"回归分支"的原型。
- **L2 P10–P12**：换成 Sigmoid/Softmax + CE，就得到分类分支；两条分支共用 $z=Wx+b$。
- **L2 Q1 / Q2**：CE 的 $-y\ln p$、$e$ 与 $\log$ 的分工，都是这张图里的一环。
- **L3**：语言模型 = 对词表做 Softmax 多分类，损失就是 CE；Perplexity $=e^{\text{CE}}$。

## Q7. 训练时 CE 的惩罚是"减到 $w$ 上"吗？完整训练流程？判别函数 / 决策区域 / 决策边界是什么？

**问题原话**：「所以这是一个训练模型的过程。当模型得出各个分类的概率时，我们拿最好的概率的结果和已知的真值比较。这时如果得到的概率大，则 ce 的惩罚值就小。那么惩罚值是减到 w 权重上的吗。整个训练的过程能否再给我完整呈现一下。判别函数、决策区域和决策边界又是什么」

**一句话答案**：不是把损失"减"到 $w$ 上，而是先算**损失对 $w$ 的梯度**，再按学习率缩小后减去：$w\leftarrow w-\eta\,\partial L/\partial w$。完整流程 = 前向算概率与 CE → 反向算梯度 → 更新参数 → 重复。判别函数是每类的打分 $g_k$；决策区域是"哪类分最高"的点集；决策边界是两类打平的地方。

### 1. 先纠正两个细节

**细节 A：训练时看的是"真值类的概率"，不是"最大的概率"。**

| 模型输出 $p$           | argmax | 真值 | CE $=-\ln p_{\text{真值}}$ |
| ------------------------ | ------ | ---- | ---------------------------- |
| $(0.40,\ 0.35,\ 0.25)$ | 类 1   | 类 1 | $0.916$                    |
| 同上                     | 类 1   | 类 2 | $1.050$                    |
| 同上                     | 类 1   | 类 3 | $1.386$                    |

- 同一个模型、同一组概率，**真值不同，损失就不同**。
- 训练时根本不需要先算 argmax；直接用真值类号去取 $p_{\text{真值}}$。
- 只有当"真值类的概率"很小时，CE 才大 —— 这通常也意味着模型把最高概率给了别的类。

**细节 B：损失是标量，$w$ 是向量，不能直接相减。**

- 把 $0.693$ 从每个权重里减掉，既没有方向，也说不清该减多少。
- 真正决定"往哪走、走多远"的，是**梯度**（每个参数各自的斜率）。

### 2. 损失、梯度、更新：三件事

| 概念                               | 是什么                                        | 形状            | 作用                       |
| ---------------------------------- | --------------------------------------------- | --------------- | -------------------------- |
| Loss $L$                         | 一个数，衡量这批预测有多差                    | 标量            | 只用于**监控**与求导 |
| Gradient $\partial L/\partial w$ | 损失对每个参数的斜率                          | 与 $w$ 同形状 | 决定**方向与大小**   |
| Update                             | $w\leftarrow w-\eta\,\partial L/\partial w$ | —              | 真正改变模型               |

- 下山类比：$L$ 是海拔，梯度是"最陡上坡方向"，负号让我们**下坡**，$\eta$ 是步长。
- 二分类（Logistic + CE）有一个非常干净的结果：

$$
\frac{\partial L}{\partial z}=p-y,\qquad \frac{\partial L}{\partial w}=(p-y)\,x,\qquad \frac{\partial L}{\partial b}=p-y
$$

- 逐符号：
  - $p$：模型给类 1 的概率；$y$：真值（0 或 1）。
  - $p-y$：**"多估了还是少估了"**。$p<y$ → 负 → 更新后 $z$ 变大；$p>y$ → 正 → $z$ 变小。
  - 乘 $x$：哪个特征大，那个权重就改得多。
- 多分类版本同样干净：

$$
\frac{\partial L}{\partial z_k}=p_k-y_k
$$

- 正确类：$p_k<1$，梯度为负 → $z_{\text{真值}}$ 被**推高**。
- 错误类：$y_k=0$，梯度为 $p_k>0$ → $z_{\text{错误}}$ 被**压低**。

> 🔭 拓展（不影响本课）：这两个梯度公式来自链式法则，本课只要求记住结论与符号方向，不要求推导。

### 3. 完整训练流程（7 步）

```
0. 准备：数据 (x, y)、初始化 w, b（常设为 0 或小随机数）
1. 前向：z = Wx + b
2. 变概率：p = Sigmoid(z) 或 Softmax(z)
3. 算损失：L = -ln p[真值类]（一个 batch 内取平均）
4. 反向：求 ∂L/∂W、∂L/∂b
5. 更新：W ← W - η·∂L/∂W，b ← b - η·∂L/∂b
6. 重复：遍历数据多轮（epoch），每轮打乱、分批（mini-batch）
7. 监控与停止：看训练/验证损失，选超参数，早停；最后冻结参数做 argmax 推理
```

伪代码：

```python
W, b = init()
for epoch in range(E):
    shuffle(data)
    for xb, yb in batches(data, B):
        z = xb @ W.T + b                  # ① 打分
        p = softmax(z)                    # ② 概率
        L = -mean(log(p[range(B), yb]))   # ③ 只看真值类
        gW, gb = backward(L)              # ④ 梯度
        W -= lr * gW                      # ⑤ 更新
        b -= lr * gb
    log(train_loss, val_loss)             # ⑥ 监控
yhat = argmax(X @ W.T + b, axis=1)        # ⑦ 推理
```

- **batch / iteration / epoch**：一次前向+反向 = 一次 iteration；一个 batch = 一小批样本；跑完整个数据集 = 一个 epoch。
- **为什么分批**：全量太慢、单样本太抖；batch 是折中，梯度取平均更稳。
- **训练与推理的分工**：训练要概率（可导）；推理要类号（argmax，不可导）。

### 4. 手算：一次完整的参数更新（二分类）

设 $x=(1,2)$、$y=1$、$\eta=0.1$，初始 $w=(0,0)$、$b=0$。

| 迭代 | $z$     | $p=\sigma(z)$ | $L=-\ln p$ | $p-y$    | 更新后 $w$        | 更新后 $b$ |
| ---- | --------- | --------------- | ------------ | ---------- | ------------------- | ------------ |
| 0    | $0$     | $0.500$       | $0.693$    | $-0.500$ | $(0.050,\ 0.100)$ | $0.050$    |
| 1    | $0.300$ | $0.574$       | $0.555$    | $-0.426$ | $(0.093,\ 0.185)$ | $0.093$    |
| 2    | $0.555$ | $0.635$       | $0.454$    | $-0.365$ | $(0.129,\ 0.258)$ | $0.129$    |

逐步看第 0 → 1 次：

$$
z=0,\quad p=0.5,\quad L=-\ln0.5=0.693
$$

$$
\frac{\partial L}{\partial w}=(p-y)x=(-0.5)(1,2)=(-0.5,\ -1),\qquad \frac{\partial L}{\partial b}=-0.5
$$

$$
w\leftarrow(0,0)-0.1\times(-0.5,-1)=(0.05,\ 0.10),\qquad b\leftarrow0-0.1\times(-0.5)=0.05
$$

- 新打分：$z=0.05\times1+0.10\times2+0.05=0.30$，$p$ 从 $0.50$ 升到 $0.574$，损失从 $0.693$ 降到 $0.555$。
- 方向直觉：$p<y$（低估了正类）→ 梯度为负 → 减去负数 → 参数变大 → $z$ 变大 → $p$ 变大。**这正是"把正确答案的概率抬上去"。**
- 表中是同一个样本反复训练；真实训练每步换样本，所以曲线会更抖，但趋势一样。

> ⚠️ 常见误解：损失大 ≠ 更新大。Sigmoid 饱和时（例如 $z=-10$、$p\approx0$），梯度几乎为 0，参数几乎不动 —— 这就是为什么分类要用 CE 而不是 MSE，也是"梯度消失"的雏形。

### 5. 多分类的一次更新：模板被拉近 / 推远

仍用 $x=(2,1)$、分数 $(2,1,-1)$、$p=(0.705,0.260,0.035)$、真值 = 类 1：

$$
\frac{\partial L}{\partial z}=p-y=(-0.295,\ +0.260,\ +0.035)
$$

- 类 1（正确）：负梯度 → $w_1$ 朝 $x$ 方向**拉近**（$\eta=0.1$ 时约加 $(0.059,0.030)$）。
- 类 2、3（错误）：正梯度 → $w_2,w_3$ 朝 $x$ 反方向**推远**。
- 直觉：每个 $w_k$ 就是类 $k$ 的"模板"；训练就是把正确模板拉向样本、把错误模板推离样本。
- 多类 CE 一次更新同时动所有类的模板，这正是"一起比较"，不是"训 K 个独立二分类器再投票"。

### 6. 判别函数（Discriminant Function）

$$
g_k(x)=w_k^Tx+b_k,\qquad k=1,\dots,K
$$

- 它是**第 $k$ 类的打分**，也是 Softmax 的输入（logits）。
- 分类规则：$\hat y=\arg\max_k g_k(x)$。
- 三个名字指同一个东西：

| 叫法                  | 场景                    |
| --------------------- | ----------------------- |
| 打分 / score          | 直观说法                |
| logit                 | 接 Softmax / Sigmoid 时 |
| discriminant function | 决策理论里              |

- 二分类的统一写法：把类 0 的判别函数固定为 $g_0(x)=0$，类 1 为 $g_1(x)=w^Tx+b$。

$$
\text{softmax}\big((g_1,0)\big)=\sigma(g_1)\ \Longrightarrow\ g_1=0 \iff p=0.5
$$

  于是"阈值 0.5"其实就是"两类打平"，二分类只是 $K=2$ 的特例。

### 7. 决策区域（Decision Region）

$$
\mathcal{R}_k=\{x:\ g_k(x)\ge g_j(x)\ \text{对所有 }j\}
$$

- 人话：**在这片区域里，类 $k$ 的分数最高**。
- 性质：
  - 区域**覆盖整个空间**（argmax 一定有返回值）；
  - 区域之间**互不重叠**（除边界）；
  - 边界上两类打平。
- 例（三个 $g$）：$g_1=x_1+x_2-1$、$g_2=x_1-x_2$、$g_3=1-x_1$：

| 区域                    | 不等式                           | 验算点       |
| ----------------------- | -------------------------------- | ------------ |
| $\mathcal{R}_1$（猫） | $x_2>0.5$ 且 $x_2>2-2x_1$    | $(2,1)$ ✅ |
| $\mathcal{R}_2$（狗） | $x_2<0.5$ 且 $x_2<2x_1-1$    | $(3,0)$ ✅ |
| $\mathcal{R}_3$（鹿） | $x_2<2-2x_1$ 且 $x_2>2x_1-1$ | $(0,0)$ ✅ |

### 8. 决策边界（Decision Boundary）

- 定义：两个判别函数打平的地方。

$$
g_i(x)=g_j(x)\ \Longleftrightarrow\ (w_i-w_j)^Tx+(b_i-b_j)=0
$$

- 这是一个**超平面**：二维是直线，三维是平面，更高维叫超平面。
- 二分类时就是 $w^Tx+b=0$，等价于 $p=0.5$。
- 上例的三条边界：

$$
x_2=0.5,\qquad x_2=2-2x_1,\qquad x_2=2x_1-1
$$

- 多类边界是**分段线性**的：每段来自一对类的平局。
- 边界只由参数决定，与损失函数无关；**训练做的事就是移动这些线**。

### 9. 训练、判别函数、区域、边界怎么连起来

```
训练：调 w, b  ──→  判别函数 g_k 变  ──→  区域/边界移动  ──→  预测改变
         ↑                                      │
         └────── CE 梯度：抬高真值类 g，压低其他类 g ──────┘
```

- CE 不直接"画边界"，它调参数；边界是参数的几何影子。
- 训练目标不是"让某条线好看"，而是让训练样本上 $g_{\text{真值}}$ 尽量大。
- 区域/边界解释"模型怎么判"；CE + 梯度解释"模型怎么学"。

### 10. 易错点 / 考点

1. **训练用真值类概率，不用最大概率**；argmax 只在推理时用。
2. **不是把 loss 减到 $w$ 上**，是减去 $\eta\times$ 梯度。
3. **loss 大 ≠ 梯度大**：饱和区梯度接近 0。
4. **梯度是"每个参数一个数"**，方向和大小都由它决定。
5. **二分类阈值 0.5 = 两类打平**；边界 $w^Tx+b=0$。
6. **决策区域覆盖全空间**，边界是共享的"墙"。
7. **多类边界是分段线性**，不是一条线。
8. **训练集 CE 降低 ≠ 泛化变好**（过拟合，见 L1）。
9. **batch 的梯度是平均**，不是求和；学习率要相应调。

### 11. 与课程的联系

- **L1**：梯度下降的通用形式 $\theta\leftarrow\theta-\eta\nabla J$，本节就是它在分类上的具体化。
- **L2 P10–P12**：Sigmoid/Softmax 提供概率，CE 提供梯度，argmax 提供类号，$g_k$ 提供几何。
- **L3**：语言模型每个 token 都做一次"$g$ → Softmax → CE → 更新"，只是 $K$ 变成词表大小。

## Q8. $\partial L/\partial w=(p-y)x$ 怎么推？$L=-\ln p$ 与 $y_k$ 的意义？二分 / 三分完整算一遍

> 本节已整理为独立讲义：[`L2_derivation.md`](L2_derivation.md)（符号表 + 函数清单 + 完整推导 + 两个算例，可单独阅读）。

**问题原话**：「[图 1] 是怎么得出来的。每次的损失函数是不是就必然是 [图 2]，那 $y_k$ 没有什么计算意义。能不能二分和三分都完整计算展示一下，不用给我代码，数学公式尽量详细一点。[图 3] 是什么意思，在后面二分和三分的计算案例里请带入生活例子以便理解。一开始解释下我们训练总共会有哪些函数，怎么推导。」

**一句话答案**：$x$ 是一条样本的**特征向量**；训练里一共有 6 个函数（打分、链接、损失、梯度、更新、评估）；$L=-\ln p$ 只是**二分类且 $y=1$** 时的特例，完整式是 $L=-[y\ln p+(1-y)\ln(1-p)]$；$y_k$ 是**选择开关**，负责挑出"真值类那一项"。下面从零推一遍，再各做一个生活化的完整算例。

### 0. 先给地图：训练里到底有哪 6 个函数

| # | 函数            | 公式                                           | 作用               | 从哪来                           |
| - | --------------- | ---------------------------------------------- | ------------------ | -------------------------------- |
| 1 | 打分 / 判别函数 | $z_k=w_k^Tx+b_k$                             | 特征 → 分数       | 线性模型假设                     |
| 2 | 链接函数        | $p=\sigma(z)$ 或 $p_k=\text{softmax}(z)_k$ | 分数 → 概率       | 概率公理 + logit 线性 / 正数归一 |
| 3 | 损失函数        | $L=-\sum_k y_k\ln p_k$                       | 概率 → 一个数     | 最大似然（负对数似然）           |
| 4 | 梯度            | $\partial L/\partial w$                      | 指出"往哪改"       | 对损失求导（链式法则）           |
| 5 | 更新规则        | $w\leftarrow w-\eta\,\partial L/\partial w$  | 真正改参数         | 一阶下山                         |
| 6 | 评估函数        | Accuracy、验证集 CE                            | 判断好坏、选超参数 | **不参与求导**             |

- 逻辑顺序：**先假设模型（1）→ 再规定怎么变概率（2）→ 再规定怎么罚（3）→ 求导（4）→ 迭代（5）→ 用（6）验收。**
- 为什么需要（5）：逻辑回归对 $w$ 求导后令其等于 0，**没有闭式解**，只能一步步迭代（线性回归可以用公式一次解出，这里不行）。
- 为什么（6）不参与：准确率不可导，只能当裁判，不能当教练。

### 1. 两个推导工具

**工具 A：链式法则**（本课只要求会用一句）

$$
y=f(u),\quad u=g(x)\ \Longrightarrow\ \frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}
$$

- 直觉：齿轮传动。大齿轮转 2 圈带动中齿轮转 3 圈，中齿轮再带动指针转 5 圈，总传动比就是 $2\times3\times5$。
- 在神经网络里，"链条"就是：$w\to z\to p\to L$，所以

$$
\frac{\partial L}{\partial w}=\frac{\partial L}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial w}
$$

**工具 B：两个基本导数**

$$
\frac{d}{du}\ln u=\frac1u,\qquad \frac{d}{du}e^{u}=e^{u}
$$

### 2. 二分类：从模型一路推到 $\partial L/\partial w$

#### 2.1 打分函数

$$
z=w_1x_1+w_2x_2+b=w^Tx+b
$$

- $x=(x_1,x_2)$：一条样本的两个特征。
- $w=(w_1,w_2)$：每个特征"多重要"。
- $b$：偏置，相当于"及格线"的整体平移。
- 这里假设 $z$ 对 $x$ 是线性的 —— 这就是"线性分类器"里的"线性"。

#### 2.2 链接函数：为什么是 Sigmoid

$$
p=\sigma(z)=\frac{1}{1+e^{-z}}
$$

- $z$ 可以是任意实数，但概率必须在 $(0,1)$，所以需要一个"压缩器"。
- 反过来看：$\operatorname{logit}(p)=\ln\dfrac{p}{1-p}=z$，即"对数几率是线性的"（见 Q3）。

#### 2.3 损失函数：从"最大化正确概率"来w

- 模型**永远只输出一个数** $p=P(y=1\mid x)$：它认为"这条是类 1"的概率，和真值无关。
- $y$ 是数据给的：若 $y=1$，模型给**真值类**的概率就是 $p$；若 $y=0$，就是 $1-p$。
- 所以"若 $y=1$"不是"模型算出来是 1"，而是"这条样本的正确答案是 1"。
- **先把 $y$ 说清楚**（它常被当成"凭空冒出来的符号"）：

| 问题                 | 答案                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| $y$ 是什么         | **Label（标签 / 真值）**：这条样本的标准答案，不是特征，也不是模型算出来的 |
| 取值                 | 二分类 $y\in\{0,1\}$；多分类写成 One-Hot 向量，如 $y=(0,1,0)$                |
| 怎么取到             | 数据集里**人工标注或事实记录**好的，训练前就固定；一条样本配一个 $y$     |
| 什么意义             | 告诉模型"这条样本正确答案是哪个类"，从而决定 CE 罚哪一项                         |
| 训练中会变吗         | **不会**。$y$ 是常数，被更新的是 $w,b$                                 |
| 和 $\hat y$ 的区别 | $y$ 是真值，$\hat y$ 是模型预测（见 Q4）                                     |
| 为什么像"没参与计算" | 它只当 0/1 开关，不用来做加减乘除的数值                                          |

- 生活对照：

| 场景 | 样本 $x$                     | 真值 $y$  | 读法                     |
| ---- | ------------------------------ | ----------- | ------------------------ |
| 考试 | （复习 1 h，做题 2 套）        | $1$       | 这个学生**通过了** |
| 邮件 | （"免费"出现 3 次，链接 5 个） | $1$       | 这封**是垃圾邮件** |
| 水果 | （重量 2，红度 3）             | $(0,1,0)$ | 这颗**是橙子**     |

- "监督学习"里的**监督**，指的就是这个 $y$：它像老师给的答案，模型只能看 $x$ 猜，猜完再对答案。
- 取到的时机：训练开始前就把 $(x,y)$ 成对准备好；每个 batch 取出一小批，$y$ 就跟着这批样本一起进来。
- 最大似然想做的事：**让这个概率越大越好**。
- 取负对数（单调递减，最大化变最小化；且把连乘变连加）：

$$
L=
\begin{cases}
-\ln p, & y=1\\[4pt]
-\ln(1-p), & y=0
\end{cases}
$$

- 合并成一个式子（$y\in\{0,1\}$）：

$$
L=-\big[y\ln p+(1-y)\ln(1-p)\big]
$$

**所以 $L=-\ln p$ 不是"必然"，只是 $y=1$ 那一半。** 当 $y=0$ 时是 $-\ln(1-p)$。

**顺便分清三个东西**（这里最容易混）：

| 东西       | 例子    | 谁给的                | 含义               |
| ---------- | ------- | --------------------- | ------------------ |
| $p$      | $0.8$ | 模型算的              | 认为"是类 1"的概率 |
| $\hat y$ | $1$   | 模型（阈值 / argmax） | 预测的类号         |
| $y$      | $1$   | **数据给的**    | 正确答案           |

- **前向传播时模型只看 $x$，看不到 $y$**；$y$ 只在算损失时登场 —— 所以不存在"默认算出 $y=1$"。
- "若 $y=1$"只是**代数分支**：$y$ 当 0/1 开关，把另一项乘 0。

**同一个 $p$，$y$ 不同，损失就不同**：

| $p$ | 真值 $y$ | 模型给**真值类**的概率 | CE                |
| ----- | ---------- | ---------------------------- | ----------------- |
| 0.8   | 1          | $p=0.8$                    | $-\ln0.8=0.223$ |
| 0.8   | 0          | $1-p=0.2$                  | $-\ln0.2=1.609$ |
| 0.2   | 1          | $p=0.2$                    | $-\ln0.2=1.609$ |
| 0.2   | 0          | $1-p=0.8$                  | $-\ln0.8=0.223$ |

- 模型输出没变，换个真值，损失就从 $0.223$ 跳到 $1.609$ —— **$y$ 是裁判，不是模型的输出**。
- 记忆：**$p$ 是模型的口气，$y$ 是标准答案，$\hat y$ 是模型的作答。**

#### 2.4 $y_k$ 到底有没有用

| 情形               | $y$         | 代入后          | 谁被罚               |
| ------------------ | ------------- | --------------- | -------------------- |
| 真值是类 1         | $y=1$       | $L=-\ln p$    | $p$ 太小 → 重罚   |
| 真值是类 0         | $y=0$       | $L=-\ln(1-p)$ | $1-p$ 太小 → 重罚 |
| 三分类，真值是类 2 | $y=(0,1,0)$ | $L=-\ln p_2$  | 只有 $p_2$ 进公式  |

- $y_k$ 的作用是**选择开关**：它把"正确类那一项"留下来，其余项乘 0 消失。
- 没有它，你没法用一个公式同时覆盖 $y=0$ 和 $y=1$，也没法写多分类。
- 它还有两个真实用途：
  - **软标签**：$y=(0.7,0.2,0.1)$ 表示"70% 猫、20% 狗、10% 鹿"（标签平滑 / 蒸馏）；
  - **类别加权**：$L=-\sum_k c_k y_k\ln p_k$，给稀有类更大权重。
- 一句话：$y_k$ **不是拿来算数值大小的，是拿来"指位置"的**。

#### 2.5 求导第一步：$\partial L/\partial p$

以 $y=1$ 为例，$L=-\ln p$：

$$
\frac{\partial L}{\partial p}=-\frac1p
$$

以 $y=0$ 为例，$L=-\ln(1-p)$：

$$
\frac{\partial L}{\partial p}=-\frac{1}{1-p}\cdot(-1)=\frac{1}{1-p}
$$

合并（对 $y\in\{0,1\}$）：

$$
\frac{\partial L}{\partial p}=-\frac{y}{p}+\frac{1-y}{1-p}
$$

**这一步不是"把两个结果相加"，而是用 $y$ 当开关**：

| $y$ | $-\dfrac{y}{p}$ | $\dfrac{1-y}{1-p}$ | 相加                  |
| ----- | ----------------- | -------------------- | --------------------- |
| $1$ | $-\dfrac1p$     | $0$                | $-\dfrac1p$ ✅      |
| $0$ | $0$             | $\dfrac{1}{1-p}$   | $\dfrac{1}{1-p}$ ✅ |

- 写法就是"第一项乘 $y$、第二项乘 $1-y$"：

$$
y\cdot\left(-\frac1p\right)+(1-y)\cdot\frac{1}{1-p}
$$

- 因为 $y\in\{0,1\}$，$y$ 本身就是一个**指示器**：$y=1$ 时它等于 1，$y=0$ 时它等于 0。
- 更稳的做法：直接对合并后的损失求导（$y$ 对 $p$ 是常数，原样保留）：

$$
\frac{\partial L}{\partial p}
=\frac{\partial}{\partial p}\Big[-y\ln p-(1-y)\ln(1-p)\Big]
=-\frac{y}{p}-(1-y)\cdot\frac{1}{1-p}\cdot(-1)
=-\frac{y}{p}+\frac{1-y}{1-p}
$$

- 图里第二行的 $\times(-1)$ 就是链式法则：$\dfrac{d(1-p)}{dp}=-1$。

通分：

$$
\frac{\partial L}{\partial p}
=\frac{-y(1-p)+(1-y)p}{p(1-p)}
=\frac{-y+yp+p-yp}{p(1-p)}
=\frac{p-y}{p(1-p)}
$$

#### 2.6 求导第二步：$\partial p/\partial z$

$$
p=\frac{1}{1+e^{-z}}=(1+e^{-z})^{-1}
$$

用链式法则（外层是 $u^{-1}$，内层是 $1+e^{-z}$）：

$$
\frac{\partial p}{\partial z}=-(1+e^{-z})^{-2}\cdot(-e^{-z})=\frac{e^{-z}}{(1+e^{-z})^2}
$$

拆成两个因子：

$$
\frac{e^{-z}}{1+e^{-z}}=1-p,\qquad \frac{1}{1+e^{-z}}=p
$$

所以

$$
\frac{\partial p}{\partial z}=p(1-p)
$$

#### 2.7 合起来：$\partial L/\partial z$

$$
\frac{\partial L}{\partial z}=\frac{\partial L}{\partial p}\cdot\frac{\partial p}{\partial z}=\frac{p-y}{p(1-p)}\cdot p(1-p)=p-y
$$

**这是一个非常漂亮的消去**：分母的 $p(1-p)$ 正好被 Sigmoid 的导数抵消。

#### 2.8 再对 $w$ 求导

$$
z=w_1x_1+w_2x_2+b\ \Longrightarrow\ \frac{\partial z}{\partial w_1}=x_1,\quad \frac{\partial z}{\partial w_2}=x_2,\quad \frac{\partial z}{\partial b}=1
$$

于是

$$
\frac{\partial L}{\partial w_1}=(p-y)x_1,\qquad \frac{\partial L}{\partial w_2}=(p-y)x_2
$$

写成向量就是图中那一行：

$$
\boxed{\frac{\partial L}{\partial w}=(p-y)x},\qquad \frac{\partial L}{\partial b}=p-y
$$

#### 2.9 代入图中的数

$x=(1,2)$、$p=0.5$、$y=1$：

$$
p-y=0.5-1=-0.5
$$

$$
\frac{\partial L}{\partial w}=(-0.5)\times(1,2)=(-0.5,\ -1)
$$

- 逐分量：对 $w_1$ 是 $-0.5\times1=-0.5$；对 $w_2$ 是 $-0.5\times2=-1$。
- 读法：$p<y$（低估真值）→ 梯度为负 → 减去负数 → 参数变大 → $z$ 变大 → $p$ 变大。

### 4. 多分类：完整推导

#### 4.1 Softmax

$$
p_k=\frac{e^{z_k}}{S},\qquad S=\sum_{j=1}^{K}e^{z_j}
$$

- 非负、和为 1；$p_k/p_j=e^{z_k-z_j}$（保序）。

#### 4.2 损失化简（关键一步）

真值类记作 $c$，One-Hot 下只有 $y_c=1$：

$$
L=-\sum_k y_k\ln p_k=-\ln p_c
$$

代入 $p_c=e^{z_c}/S$：

$$
L=-\ln\frac{e^{z_c}}{S}=-\ln e^{z_c}+\ln S=-z_c+\ln S
$$

- 逐项：$-\ln e^{z_c}=-z_c$；$-\ln(1/S)=+\ln S$。
- 这一步把"对数里套分数"变成了"一个线性项 + 一个 log-sum"，是求导干净的原因。

#### 4.3 对 $z_k$ 求导

$$
\frac{\partial L}{\partial z_k}=\frac{\partial}{\partial z_k}\big(-z_c+\ln S\big)
$$

- 第一项：$k=c$ 时导数是 $-1$，否则 $0$。这正好是 $-y_k$。
- 第二项：

$$
\frac{\partial \ln S}{\partial z_k}=\frac1S\cdot\frac{\partial S}{\partial z_k}=\frac1S\cdot e^{z_k}=p_k
$$

合起来：

$$
\boxed{\frac{\partial L}{\partial z_k}=p_k-y_k}
$$

分情况看更直观：

| 类     | $y_k$ | 梯度 $p_k-y_k$ | 效果                      |
| ------ | ------- | ---------------- | ------------------------- |
| 正确类 | 1       | $p_c-1<0$      | 把 $z_c$ **推高** |
| 错误类 | 0       | $p_k>0$        | 把 $z_k$ **压低** |

#### 4.4 对参数求导

$$
z_k=w_k^Tx+b_k\ \Longrightarrow\ \frac{\partial z_k}{\partial w_k}=x,\qquad \frac{\partial z_k}{\partial b_k}=1
$$

所以

$$
\frac{\partial L}{\partial w_k}=(p_k-y_k)x,\qquad \frac{\partial L}{\partial b_k}=p_k-y_k
$$

- 直觉：每个 $w_k$ 是类 $k$ 的"模板"；正确类模板被拉向 $x$，错误类模板被推离 $x$。

### 6. 再回答三个"是不是必然"

**（1）损失函数必然是 $-\ln p$ 吗？**

- 不必然。$-\ln p$ 只是"二分类 + 真值为 1"。
- 完整二分类是 $L=-[y\ln p+(1-y)\ln(1-p)]$；多分类是 $L=-\sum_k y_k\ln p_k$。
- 它之所以是"标配"，是因为它等于**伯努利 / 类别分布的负对数似然**（见 Q6）。换成高斯假设就会得到 MSE。

**（2）$y_k$ 没有计算意义？**

- 它的意义是"指位置"，不是"提供数值"。
- 没有它：写不出统一公式、写不出多分类、也没法做软标签和类别加权。

**（3）$L=-\ln p$ 里的 $p$ 是最大概率吗？**

- 不是。**必须是真值类的概率**。argmax 只在推理时用（见 Q7 的两个纠正）。

### 7. 常见误解

1. **把 $-\ln p$ 当成通用式**：漏掉 $y=0$ 的 $-\ln(1-p)$。
2. **用最大概率算损失**：真值类概率才是损失的自变量。
3. **以为 $y_k$ 是权重**：它是 0/1 开关；权重是另外乘的 $c_k$。
4. **以为梯度是"损失值"**：梯度是斜率，损失是高度。
5. **以为 $p(1-p)$ 会留在梯度里**：它被 Sigmoid 导数约掉了，所以是 $p-y$。
6. **多分类梯度只改正确类**：错误类也会被压低，所以所有 $w_k$ 都动。
7. **以为 $x$ 是一个数**：$x$ 是特征向量，$x=(1,2)$ 表示两个特征。

### 8. 与课程的联系

- **P10**：$p=\sigma(w^Tx)$ 与 $L=-\ln p$。
- **P11**：argmax 与阈值 0.5。
- **P12**：$z_k$ 的 argmax → 决策区域；本节 5.7 的三条边界就是它。
- **L1**：$\theta\leftarrow\theta-\eta\nabla J$ 是同一个更新规则。
- **L3**：语言模型把 $K$ 换成词表大小，其余推导一字不改。

## Q9. Representation-based、编码器、分类头分别是什么意思？

**问题原话**：「Representation-based，编码器，分类头都是什么意思」

**一句话答案**：**Encoder（编码器）**把原始输入 $x$ 变成特征向量 $h$；这个 $h$ 就是 **representation（表示）**；**classifier head（分类头）**是接在 $h$ 后面、把特征变成类别分数的小分类器。**Representation-based（基于表示）** 的迁移学习 = 借用别人训好的编码器（冻结不动），只训练一个新的分类头。

### 1. 三个词一张表

| 词 | 中文 | 是什么 | 输入 → 输出 | 生活类比 |
|---|---|---|---|---|
| Encoder | 编码器 | 一个预训练好的网络主体（也叫 backbone / feature extractor） | 图片 / 文本 $x$ → 向量 $h$ | 翻译官：把原文翻成一种通用语言 |
| Representation | 表示 / 特征 | 编码器输出的那串数字 $h$，以及它所在的空间 | — | 译文本身 |
| Classifier head | 分类头 | 接在 $h$ 后面的小分类器，常只有一层线性层 | $h$ → $K$ 个分数 | 只看译文做判断的裁判 |

- 三者关系：

$$x\ \xrightarrow{\text{Encoder}}\ h\ \xrightarrow{\text{Head}}\ z=Wh+b\ \xrightarrow{\text{softmax/argmax}}\ \hat y$$

- 记忆：**编码器负责"看懂"，分类头负责"下结论"。**

### 2. 编码器（Encoder）到底是什么

- 定义：把高维原始输入压成低维语义向量的网络部分。
- 例：ResNet 输入 $224\times224\times3$ 的图，输出 $512$ 维向量 $h$。
- 关键：**编码器不是分类器**。它不输出"猫/狗"，只输出"这图长什么样"的数字描述。
- 它通常在超大数据集（如 ImageNet 1000 类）上预训练好，别人训完你直接用。
- 同义叫法：backbone（骨干）、feature extractor（特征提取器）、body。

### 3. 表示（Representation）是什么

- 就是 $h$ 这个向量；也指它所在的**新特征空间**。
- 在原始像素空间里，"猫"和"狗"的距离没有语义；在表示空间里，语义相近的样本会靠近。
- 所以 P29 说"Representation-based 迁移 = 换一个更好的度量空间"。
- 类比：把英文书翻译成中文后，你可以用中文做检索、聚类、分类 —— **译文本身才是资产**，原书的 1000 类任务已经不重要了。

### 4. 分类头（Classifier Head）是什么

- 定义：接在 $h$ 后面的小网络，把特征映射成 $K$ 个分数：

$$z_k=w_k^Th+b_k,\qquad k=1,\dots,K$$

- 最常见的形式：**一个线性层**（linear layer），所以也叫 linear head / linear probe（线性探针）。
- 参数量很小：$K\times d+K$。
  - 例：$d=512$、$K=10$ → $512\times10+10=5130$ 个参数；
  - 同一模型编码器约 2300 万参数。
- 换任务时**只换头**：10 类换成 3 类，就是换一个 $3\times512$ 的矩阵。

### 5. Representation-based 的完整含义

- 全称：Representation-based Deep Transfer Learning（基于表示的深度迁移学习）。
- 做法：
  1. 拿一个预训练编码器；
  2. **冻结**（freeze）它的全部参数；
  3. 在 $h$ 上训练一个新的分类头。
- "冻结"= 反向传播时不更新编码器参数，它们被当成常数；梯度只更新头。
- 适合：目标数据很少（$<1000$ 条）、算力有限、源域与目标域还算相似。
- 代价：特征不完全贴合新任务，精度有上限。

### 6. 与另外两种迁移的区别

| 类型 | 迁移什么 | 关键操作 | 训练谁 | 典型数据量 |
|---|---|---|---|---|
| Representation-based | **表示（特征）** | 冻结编码器 + 换头 | 只训分类头 | $<1000$ |
| Model Sharing-based | **参数（层）** | 解冻 + 小学习率微调 | 部分 / 全部层 | $1000$–$50000$ |
| Instance-based | **样本** | 过滤 + 重加权源域样本 | 全部参数 | 源域样本可复用 |

- 三者回答同一个问题："迁移的到底是什么？" —— 特征 / 参数 / 样本。
- 形象说法：借眼睛 / 借大脑再改 / 借题库挑题。

### 7. 小算例：头在做一件多简单的事

设编码器把一张图变成 $h=(1,2)$（真实里是 512 维，这里缩成 2 维方便手算），三类分类头：

$$z_{\text{猫}}=1.5h_1+0.5h_2-1,\quad z_{\text{狗}}=-0.5h_1+2h_2-2.5,\quad z_{\text{鹿}}=-h_1-h_2+3$$

代入 $h=(1,2)$：

$$z=(1.5,\ 1.0,\ 0)$$

$$\text{softmax}(z)=(0.547,\ 0.331,\ 0.122)\ \Rightarrow\ \hat y=\text{猫}$$

- 头的参数量：$3\times2+3=9$ 个。
- 编码器的参数一个都没动；训练只改这 9 个数。
- 若真值是猫，$L=-\ln0.547=0.604$；梯度只回传到这 9 个参数。

### 8. 常见误解

1. **"编码器就是分类器"**：错，它只输出特征，不输出类别。
2. **"表示就是原图"**：错，表示是编码后的向量，维度、语义都变了。
3. **"分类头很大"**：错，通常只有一层线性层，参数量远小于编码器。
4. **"冻结 = 删除"**：错，冻结只是不更新，前向仍然要算。
5. **"迁移的是模型"**：Representation-based 迁移的是**表示能力**；参数迁移属于 Model Sharing。
6. **"换头等于换模型"**：编码器不变，只换最后那层。

### 9. 与课程的联系

- **P13**：$x\to$ Encoder $\to h\to$ Classifier $\to$ 分数，是本讲的枢纽图。
- **P29–P32**：表示空间、换空间、编码器不是分类器。
- **P31**：冻结编码器、只训头、$<1000$ 样本。
- **P44**：解冻 + 微调，属于 Model Sharing，不是 Representation-based。
- **P50**：决策矩阵按数据量 / 相似度选这三种方法。
