6. **每次会话结束必须保存**：即使用户只说"保存"，也要写

## 学生数学水平校准（重要）

> 参考仓库：<https://github.com/gujunyang/Math>（学生的 ML 数学学习系统）
> 校准日期：2026-10-22

### 已掌握（不要再从定义讲起）

- **初等线性代数**：向量、矩阵、矩阵乘法、转置、单位矩阵、逆（基础）
- 内积、L1/L2 范数、距离、余弦相似度（基础层面）
- 单变量求导（会算基本函数的导数）
- Python / NumPy 基础
- 诊断测试 10 题 9 对；但**不要据此拔高到矩阵微积分**

### 尚未学（讲到时必须降级或明确标注"后面才学"）

- **正规方程、最小二乘、正交投影**（还没到）
- 特征值/特征分解、SVD、伪逆
- 矩阵微分、雅可比、链式法则、反向传播
- 多元微积分、Taylor 展开、Hessian、凸性、牛顿法
- **概率论、数理统计**（期望、方差、分布）
- **最优化**（收敛性、学习率上界、凸优化）

### 讲解深度规则

**不要做**：
- 不解释斜率、直线方程、求和符号 $\sum$、向量/矩阵乘法、内积/范数/距离/余弦的定义。
- **不讲**正规方程、$(X^TX)^{-1}$、矩阵求导、期望分解、特征值、收敛性证明、VC 维。
- 不写"每往右走一格""勾股定理的推广""把数加起来"这类初等铺垫。
- 不把"初等线代已学"误当成"矩阵微积分/统计/最优化已学"。

**要做**：
- 公式以**标量展开**为主，矩阵只作紧凑记号（如 $\hat y=X\theta$），并做维度检查；不要求矩阵求导。
- ML 概念（损失、梯度下降、过拟合、假设类、归纳偏置）讲透直觉与动机。
- 推导只做**一阶、可手算**的：例如 MSE 对单个参数用 $\sum_i$ 展开求导，不跳到 $\nabla_\theta J$。
- 统计量（均值、标准差、期望）第一次出现时用一句话定义，不假设已学。
- 优化只讲"沿负梯度方向走 + 学习率大小的影响"，不讲收敛条件/Taylor/凸性证明。
- 超纲内容用 `> 🔭 拓展（不影响本课）` 折叠式标注，学生可跳过。

**自检**：如果一段推导需要矩阵微积分、概率期望或最优化理论才能读懂，就删掉或降级为"结论 + 直觉"。

> 若学生数学进度更新，先读其 Math 仓库的 `系统/05_学习进度/progress.json`，再调整深度；**以学生当次说明为准**。

```powershell
# 只提取有意义的插图（推荐）

```

### 2. 写 `Lx_notes.md`
必须包含：

- **本讲地图**：这一节在整门课中的位置、学完能做什么。
- **逐页/逐主题三件套**：
  1. `> 原文`（英文原句，可适当合并同一页的要点）
  2. **中文翻译**
  3. **讲解**（直觉 + 例子 + 常见误解；数学深度按校准表）
- **公式**：行内 `$...$`，独立 `$$...$$`；每个公式后必须有
  "**符号解释 / 直觉**：每个符号是什么、这项在干嘛"。
- **图片**：`![说明](images/文件名.png)`；无图可提时写 `[图片：描述]` 并给提取建议。
- **小结表 / 易错点 / 与后续课程的联系**。

写作要求：
- 术语首次出现：`English Full Name (ABBR, 中文, 一句话解释)`。
- **术语以英文为主，中文放括号**（见下条「术语格式规范」）；不写"显然""易得"；每一步推导都要有理由。
- 涉及数字的例子要真的算对，并展示中间步骤。
- 讲义中的口误或过时说法，用 `> ⚠️ 注意` 指出并纠正（例如把参数 m, c 叫作"常数"）。
- 数学深度遵守「学生数学水平校准」：跳过斜率等初等数学，但不引入矩阵微积分、正规方程、期望分解、最优化理论。

#### 术语格式规范（硬性）

> 原因：考试、课件、代码、招聘都用英文术语；只写中文会让学生考场上认不出词。

1. **首次出现**：`English Full Name (ABBR，中文)`，例如
   `Mean Squared Error (MSE，均方误差)`。
   - 没有通用缩写时：`Standardization（标准化）`。
   - 一句话解释接在后面，例如：`…，衡量预测值与真实值差多少`。
2. **之后一律用英文缩写**（MSE / KNN / CNN / GD），不用中文代替；中文只在需要时以括号补一次，不反复出现。
3. **标题、表格表头、公式符号名**优先用英文术语。
4. **不要整段翻译术语**：正文叙述可以是中文，但术语本身保留英文原文。
5. 例外：纯操作说明（如"虚拟环境""打开终端"）、课程管理类内容（评分、政策）可用中文为主。
6. 已写好的 notes 若出现"中文（English）"顺序，逐步改为"English（中文）"。

#### 排版规范（硬性）

> 原因：学生反馈"翻译堆在一起看不懂"。课件原版是分点、留白的，翻译也应保持同样的呼吸感。

**每个页面 = 一张卡片，固定三段顺序：**

```markdown
#### P24 What is the best $m$ and $c$?

> **原文**：
> • 第一条
> • 第二条

$$公式独立成行$$

**中文**

- 第一条译文
- 第二条译文

**讲解**

- 一个要点一条，不写大段
```

**细则**

1. **原文**：整段进引用块，**保留原有的 `•` 分点和换行**，绝不压成一行。
2. **中文**：必须是**列表或分行**，条数与原文分点尽量一一对应；原文是整段叙述时才用短段落。
3. **公式**：`$$...$$` 前后各留一个空行，独立成块；不塞在句子中间。
4. **讲解**：以 `-` 列表为主；每个 bullet 只讲一件事；对比用表格。
5. **长段落上限**：单段 ≤ 3 句或 ≤ 120 字；超了就拆成 bullet。
6. **页与页之间**用 `---` 分隔；小节标题用 `###`，页面用 `####`。
7. **图片**：紧跟对应原文/译文，独占一行，前后留空行。
8. 不要用多层缩进表达并列关系（容易乱），改用平铺 bullet 或表格。

**自检**：把窗口调窄到手机宽度，若出现"一整屏全是字"的段落，就是排版不合格。

### 3. 写 `Lx_outline.md`（要领提纲）
1–2 页，供复习和考前速览。固定结构：

4. **流程/对比表**：如 ML pipeline、分类 vs 回归、训练/验证/测试、过拟合 vs 欠拟合。

6. **自测 5 问**（只给问题，答案指向 notes 对应小节）。
7. **与下一讲的衔接**。

## 教学原则 (Teaching Rules)

1. **先结构，后计算；先直觉，后形式**：先讲"它在干什么"，再写公式，最后才说严格定义。数学定义不生活化，ML 概念才用类比。
2. **一个概念一个锚点例子**：KNN 用"近朱者赤"，梯度下降用"下山"，过拟合用"背答案"。
3. **对比教学**：分类 vs 回归、训练集 vs 验证集 vs 测试集、过拟合 vs 欠拟合、L1 vs L2。
4. **公式三问**：这个符号是什么？这一项在惩罚/奖励什么？把参数调大调小会发生什么？
5. **不假设学生记得上一节**：关键处用一句话回顾。
