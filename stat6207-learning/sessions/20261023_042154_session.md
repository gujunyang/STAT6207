## 推导主线（可复习）

1. **6 个函数**：打分 $z_k=w_k^Tx+b_k$ → 链接 $\sigma$/softmax → 损失 CE → 梯度 $\partial L/\partial w$ → 更新 $w\leftarrow w-\eta g$ → 评估（acc / val CE，不参与求导）。
2. **二分类**：
   - $L=-[y\ln p+(1-y)\ln(1-p)]$；
   - $\partial L/\partial p=(p-y)/[p(1-p)]$（通分得到）；
   - $\partial p/\partial z=p(1-p)$；
   - 相乘消去 → $\partial L/\partial z=p-y$；
   - 再乘 $x$ → $\partial L/\partial w=(p-y)x$。
3. **$L=-\ln p$ 只是 $y=1$ 的特例**；$y=0$ 时是 $-\ln(1-p)$；$y_k$ 是 0/1 选择开关，还支持软标签与类别加权。
4. **多分类**：$L=-z_c+\ln S$ → $\partial L/\partial z_k=p_k-y_k$ → $\partial L/\partial w_k=(p_k-y_k)x$。
5. **数值**：
   - 考试例：$p:0.500\to0.574\to0.635$，$L:0.693\to0.555\to0.454$。
   - 水果例：$p=(0.2685,0.7297,0.0018)$，$L=0.3151$；更新后 $p=(0.1473,0.8512,0.0014)$，$L=0.1611$。
6. **几何**：水果例三条边界 $x_1=x_2$、$x_1+x_2=10/3$、$x_1+2x_2=5$，三个区域用 $(4,1),(2,3),(1,1)$ 验算。
