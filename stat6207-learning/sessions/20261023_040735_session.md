## 讲解要点（可复习）

1. **纠正 1**：训练用 $p_{\text{真值类}}$，不是 argmax 出来的最大概率；同一组概率换个真值，CE 就不同。
2. **纠正 2**：损失是标量，不能直接减到 $w$；更新的是**梯度**：$w\leftarrow w-\eta\,\partial L/\partial w$。
3. **干净梯度**：二分类 $\partial L/\partial z=p-y$；多分类 $\partial L/\partial z_k=p_k-y_k$。
4. **符号直觉**：$p<y$ → 负梯度 → 参数变大 → 概率抬高；正确类被推高、错误类被压低。
5. **完整流程**：初始化 → 前向 → 损失 → 反向 → 更新 → 多 epoch / mini-batch → 监控 → 冻结 + argmax。
6. **手算轨迹**：$L=0.693\to0.555\to0.454$，$p=0.500\to0.574\to0.635$（$x=(1,2),y=1,\eta=0.1$）。
7. **判别函数**：$g_k=w_k^Tx+b_k$ = 打分 = logit；二分类可写成 $g_0=0,\ g_1=w^Tx+b$，阈值 0.5 就是两类打平。
8. **决策区域**：$g_k$ 最大的点集，覆盖全空间、互不重叠；**决策边界**：$g_i=g_j$ 的超平面，多类时分段线性。
9. **四者关系**：训练调 $w$ → $g_k$ 变 → 区域/边界移动 → 预测变；CE 只调参数，边界是几何影子。
