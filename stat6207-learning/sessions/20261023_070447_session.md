## 讲解要点（可复习）

1. **流水线**：$x\to$ Encoder $\to h\to$ Head $\to z\to$ softmax/argmax $\to\hat y$。
2. **Encoder**：输入变特征向量；只"看懂"，不"下结论"；同义：backbone / feature extractor。
3. **Representation**：编码器输出的 $h$ 与它所在的空间；语义相近的样本在空间里靠近。
4. **Classifier head**：接在 $h$ 后的小分类器，常为一个线性层；参数量 $Kd+K$。
5. **Representation-based**：冻结编码器 + 只训新头；适合 $<1000$ 样本。
6. **对比**：迁移特征 / 迁移参数 / 迁移样本 = 借眼睛 / 借大脑再改 / 借题库挑题。
7. **算例**：$h=(1,2)$、三类头 → $z=(1.5,1,0)$、$p=(0.547,0.331,0.122)$、$\hat y=$ 猫，只有 9 个参数被训练。
8. **误解**：编码器不是分类器；冻结不是删除；换头不是换模型。

## 关键结论

- 学生此前把"编码器 / 表示 / 分类头"当成一个东西；现已拆成"看懂 → 特征 → 下结论"三段。
- 与 P44 的 Model Sharing（解冻微调）区分清楚：一个冻、一个不冻。
- 待巩固：表示空间与原始像素空间的区别；linear probe 的参数量级。
