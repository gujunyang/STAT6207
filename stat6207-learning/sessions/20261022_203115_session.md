## 设计约定（以后 L3–L6 沿用）

1. 思维导图只放**关键词**，层级 ≤ 4，根节点 = "Lx + 三个主模块"。
2. 知识地图用**带方向的关系**，不只画目录：
   - 实线 = 流程 / 依赖（数据 → 模型 → 损失 → 更新）；
   - 虚线 = 影响 / 选择（超参数 → 验证集、数据量 → 迁移策略）。
3. 图后必须跟「60 秒回忆路线」：6–8 步自问，每步标 notes 页码。
4. 知识地图末端标出下一讲（Lx → Lx+1），保持全课程连贯。
5. 图必须是可渲染的 Mermaid；已用 `mermaid@11` parser 校验 4 个代码块全部通过。

---

## 关键结论

- L1 的主线是**一条训练闭环**：数据 → 模型 → 损失 → 梯度 → 评估。
- L2 的主线是**三个工程问题**：怎么分类（线性打分）、数据不够（迁移）、模型太大（本地部署）。
- 两讲的连接点：L1 的线性模型 → L2 的多维/多类打分；L2 的 token 预测 → L3 的自回归生成。
