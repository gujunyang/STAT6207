## 讲解要点（可复习）

1. **$\hat y$ = 预测类别**；帽子表示"估计"，与真值 $y$ 相对。回归里是数，分类里是类号。
2. **$\arg\max_k$ 返回下标**，$\max_k$ 返回值。概率 $(0.1,0.7,0.2)$ → argmax = 2，max = 0.7。
3. **整句 = "每类概率都算，谁最高报谁"**。
4. **分工**：线性分类器管打分 $z_k=w_k^Tx+b_k$；Sigmoid / Softmax 管变概率；argmax 管选类。
5. **"线性"只修饰打分**，"分类"发生在 argmax —— 这是学生原本没连上的那一环。
6. **二分类**：$\arg\max\{p,1-p\}$ ⟺ $p>0.5$ ⟺ $w^Tx>0$，三步等价。
7. **多类**：argmax 的几何后果就是决策区域，边界在 $g_i=g_j$。
8. **训练 / 预测分离**：CE 可导用于训练；argmax 不可导，只用于推理。

## 关键结论

- 学生已理解线性分类，本次补上"打分 → 概率 → 选类"的最后一环。
- 仍可能混淆：$\hat y$ 与概率；$\arg\max$ 返回值 vs 下标；二分类比较对象是 $1-p$ 而不是 0。
- 已给出代码对应：`np.argmax`、`torch.argmax`、`predict()` vs `predict_proba()`。
