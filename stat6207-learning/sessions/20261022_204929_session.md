## 讲解要点（可复习）

1. **$\exp(x)=e^x$**，同义；`exp` 只是函数写法，`np.exp`、`torch.exp` 都是它。
2. **$e$ 的来源**：连续复利 $\lim(1+1/n)^n$；本质是"增长率正比于自身"（$y'=y$）的天然单位。
3. **$e$ 的核心性质**：$(e^x)'=e^x$、$(\ln x)'=1/x$ —— 导数不带多余常数，所以全行业选它当底。
4. **$\log$ 的核心作用**：把乘法变加法。$\ln(ab)=\ln a+\ln b$、$\ln(a^b)=b\ln a$。
5. **成对关系**：$e$ 管"加 → 乘"（Softmax / Sigmoid / 高斯），$\log$ 管"乘 → 加"（CE / NLL / 对数似然）。
6. **高斯 + 取对数 = MSE**：$\exp$ 被 $\ln$ 消掉，平方从指数里掉下来，才有回归的平方损失。
7. **Softmax 的灵魂**：$p_i/p_j=e^{z_i-z_j}$，打分差 1 → 概率差 $e\approx2.72$ 倍；整体平移概率不变。
8. **工程坑**：$e^{1000}$ 溢出、$0.01^{1000}$ 下溢、$\log0=-\infty$ → log-sum-exp + clip + 框架自带 loss。

## 关键结论

- 学生已理解 CE 的惩罚形状（Q1），本次补上"为什么惩罚要写成 $-\log$"的底层理由：连乘 → 相加 + 导数 $-1/p$。
- 学生原有的"$\exp$ 就是 $e$ 的指数"直觉正确，本次把它接到"连续增长 / 造概率"的动机上。
- 仍需巩固：$\log(a+b)\neq\log a+\log b$；ML 里 $\log$ 默认是 $\ln$；Softmax 的平移不变性。
